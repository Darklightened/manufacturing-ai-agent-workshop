# 제조 AI Agent 실습

공개 조립 영상을 보면서 **회사 자료 → 공정 정보 → 작업 진행 → 확인 질문 → 판정 → 보고서**를 직접 따라가는 강의용 웹앱입니다.

**기본 전자 조립은 보여주기 쉽게 구성한 ‘강의용 예시’입니다.** 장면은 실제 공개 영상이고, AI 역할의 설명·질문·판정은 수업을 위해 작성했습니다. 작업자 답변과 검사 기준에 따라 결과가 바뀝니다. 수업 중 GPU, API 키, 모델 설치는 필요 없습니다.

## 온라인 실습

**[실습 페이지 열기](https://darklightened.github.io/manufacturing-ai-agent-workshop/)** · **[강의 자료 다운로드](https://darklightened.github.io/manufacturing-ai-agent-workshop/downloads.html)**

수강생은 위 링크를 Chrome 또는 Edge에서 열고 실습을 선택합니다. 로그인, Python 설치, API 키가 필요 없습니다. 입력과 진행 기록은 사용 중인 브라우저에 저장됩니다. 다른 PC로 옮길 때는 **진행 내보내기**를 이용합니다.

## 오프라인 실습

전체 실습팩을 풀고 `11_21_seminar` 폴더에서 실행합니다. Python 3과 브라우저가 필요합니다.

```sh
python3 scripts/serve.py
```

위 명령은 macOS·Linux용입니다. Windows에서는 `py -3 scripts/serve.py`를 사용하세요. `python`이 Python 3으로 연결된 환경에서는 `python scripts/serve.py`도 사용할 수 있습니다. 터미널은 실습 중 열어 둡니다.

브라우저에서 `http://127.0.0.1:8921/`을 엽니다. 수강생에게는 강사가 준비한 웹 주소만 알려 주어도 됩니다. 전체 앱은 PDF worker와 SQLite WASM을 사용하므로 HTML 더블클릭 대신 위 서버로 여세요. 저장한 개별 보고서는 더블클릭으로 열 수 있습니다.

1. **전자 조립 실습 시작**을 누릅니다.
2. 준비된 회사 SOP PDF·검사 기준 CSV를 불러오고 **정보 구축**을 누릅니다.
3. **작업 설정으로**를 누르고 공정·작업 순서·검사 기준을 확인한 뒤 **작업 시작하기**를 누릅니다.
4. **준비 장면 확인하기**, 이후 **다음 장면 확인하기**로 준비·회로·프로펠러·배터리·스위치·최종 확인을 따라갑니다.
5. 배터리 방향 질문에서 **질문 확인**을 먼저 누른 뒤 **방향을 확인했습니다**를 선택합니다.
6. **결과 확인 · 보고서 만들기** → **보고서 만들기**를 누르고 **사진 포함 HTML 저장**과 **검수조서 저장**으로 결과를 저장합니다.

두 번째 시도에서는 결과 화면의 **답변 다시 확인하기** → **질문 확인**을 누르고 ‘반대로 들어가 있습니다’를 선택하거나, 배터리 항목의 **시각 증거만 인정**을 선택하고 **기준 적용 · 재판정**을 눌러 비교합니다. 같은 영상에서도 어떤 정보를 확인했고 어떤 기준으로 판정했는지가 보고서에 남습니다.

## 무엇이 실제로 동작하나요?

| 기능 | 동작 |
|---|---|
| 문서 정보 구축 | PDF.js로 실제 PDF 텍스트 추출, CSV 검사 기준 검증, SQLite 구성 |
| 영상·설명 | 원본 영상/프레임 + 미리 작성한 강의용 관찰 예시 |
| 질문과 답변 | 수강생이 선택한 답변을 대상·질문·시각과 함께 기록 |
| 판정 | 관찰·작업자 답변·증거 인정 기준을 결정적 제어기로 재계산 |
| 보고서 | 현재 기록에서 사진 포함 HTML·검수조서·CSV·JSON·SQLite 생성 |
| 저장·복원 | 같은 주소에서 새로고침 복원, JSON 내보내기·가져오기 |

질문 듣기는 브라우저 음성 출력을 사용합니다. 답변은 버튼 또는 텍스트로 입력하며 음성 인식 기능은 포함하지 않습니다. 강의용 예시는 실제 생산 승인이나 모델 정확도 평가가 아닙니다.

## 계측 판독 — 제품에서 검수조서까지

계측 실습은 가상 **다온정밀의 플랜지 부시**를 검사합니다. 제품과 도면은 강의를 위해 만든 일관된 예시입니다.

1. **표준형 / 정밀형** 제품을 고릅니다. 제품별 도면·개정·검사 대상·허용 범위를 불러옵니다.
2. 예제 SOP PDF와 CSV로 **검사 기준 불러오기 · 정보 구축**을 실행합니다. **검사 시작 준비**에서 A외경·B길이·C두께를 확인한 뒤 **측정 기록 시작**을 누릅니다.
3. 계측 장면을 차례로 기록합니다. A는26.30mm, B는40.02mm가 도면 위치와 검사표에 들어갑니다.
4. C의 `5.?8 mm`에는 확정값을 넣지 않고 질문합니다. **질문 확인**을 누르고 값 `5.78`, 단위 `mm`를 입력한 뒤 **확인값 기록**을 누르면 두께 판정을 계산합니다.
5. **검수조서 만들기**로 결과를 검토한 뒤 다시 **검수조서 만들기**를 누릅니다. **검수조서 저장**으로 제품·도면·기준·측정값·질문/답변을 한 파일에 남깁니다.

표준형은 예시 확인 후3개 항목이 충족됩니다. 정밀형은 길이 허용 범위가 좁아40.02mm가 불일치입니다. 기준을 바꾸거나578mm처럼 잘못된 값을 입력해도 원래 숫자를 임의로 고치지 않습니다. 도면 원래 기준과 실습 중 바꾼 기준은 별도로 표시합니다.

## 추가 실습과 강사용 자료

이전 독립 계측 판독, 기계 조립, 오류 사례와 부품 교체 사례도 보존했습니다. 강사용 이전 계측 사진은 서로 다른 장비 사례이고, 새 플랜지 부시 실습은 같은 가상 제품을 일관되게 그린 강의용 도해입니다. 기계 영상은 호환성에 따라 원본 프레임으로 진행합니다.

이전에 수집한 전자 조립 실제 모델 응답은 **강사용 참고 경로**로 남겨 두었습니다. 기본 실습에서는 불러오지 않습니다. 원본 요청·응답과 과거 검수는 [별도 기록](docs/recorded_electronics_v1/RESULTS.ko.md)에 있습니다.
