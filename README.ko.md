# 제조 AI Agent 실습

**작업자 화면과 모니터링 화면을 분리했습니다.** 작업 설정 후에는 큰 작업 영상과 오른쪽 위 검사 항목을 표시합니다. 통과한 항목은 ✓로 남고 다음 미완료 항목이 자동으로 강조됩니다. 검사 기록을 확인하면 모니터링 화면으로 바뀌고, 다음 작업을 시작하면 작업자 화면으로 돌아옵니다. 계측값은 도면의 해당 치수 옆에 기록되며, 결과는 A4 검수조서로 저장합니다. [새 화면 안내](docs/worker_monitor_v3/README.ko.md).

슬라이드도 현재 작업자·모니터링 화면과 검사 항목 자동 체크에 맞춰 155장으로 갱신했습니다.

공개 조립 영상을 보면서 **회사 자료 → 공정 정보 → 작업 진행 → 확인 질문 → 판정 → 보고서**를 직접 따라가는 강의용 웹앱입니다.

**기본 전자 조립은 보여주기 쉽게 구성한 ‘강의용 예시’입니다.** 장면은 실제 공개 영상이고, AI 역할의 설명·질문·판정은 수업을 위해 작성했습니다. 작업자 답변과 검사 기준에 따라 결과가 바뀝니다. 수업 중 GPU, API 키, 모델 설치는 필요 없습니다.

## 오프라인 실습

전체 실습팩을 풀고 `11_21_seminar` 폴더에서 실행합니다. Python 3과 브라우저가 필요합니다.

```sh
python3 scripts/serve.py
```

위 명령은 macOS·Linux용입니다. Windows에서는 `py -3 scripts/serve.py`를 사용하세요. `python`이 Python 3으로 연결된 환경에서는 `python scripts/serve.py`도 사용할 수 있습니다. 터미널은 실습 중 열어 둡니다.

브라우저에서 `http://127.0.0.1:8921/`을 엽니다. 수강생에게는 강사가 준비한 웹 주소만 알려 주어도 됩니다. 전체 앱은 PDF worker와 SQLite WASM을 사용하므로 HTML 더블클릭 대신 위 서버로 여세요. 저장한 개별 보고서는 더블클릭으로 열 수 있습니다.

1. **전자 조립 실습 시작**을 누릅니다.
2. 회사 자료 ZIP을 풀고 **폴더 전체 업로드**에서 다온에듀테크를 선택합니다. 파일을 선택·미리보기한 뒤 **선택 자료로 정보 구축**을 누릅니다.
3. 배터리 기준을 **배터리 삽입(battery)** 작업으로 수정해 저장합니다. **검토 완료 · 온톨로지 보기** → **자료 구축 완료 · 작업 설정으로**를 누릅니다.
4. **김민수 / DA-024** 등 이름과 사번을 입력하고 사진 또는 예시 프로필을 선택한 뒤 **등록하고 인증으로**를 누릅니다.
5. 등록 정보 확인에 체크하고 인증 번호 **6421**을 입력한 뒤 **인증 확인**을 누릅니다. 실제 얼굴 인식이 아닌 강의용 화면 인증입니다.
6. **바람빛 회로 키트 · 전자 조립**을 선택하고 **작업 시작 · 영상 연결** → **영상 재생**을 누릅니다. 1배·2배·4배 중 속도를 선택할 수 있습니다.
7. 오른쪽 위 검사 항목에 ✓가 쌓이는 것을 확인합니다. 각 단계가 통과하면 **기록 확인 · 모니터링으로**를 누르고, 검사표와 작업 기록을 본 뒤 **다음 작업 시작**을 누릅니다. 배터리 방향 질문은 **질문 확인** 후 직접 답합니다. 불일치·미확인 답변이면 다음 단계가 보류됩니다.
8. 마지막 단계도 **기록 확인 · 모니터링으로**를 누른 뒤 **검수 완료 · 결과 보기** → **검수 보고서 보기**를 누르고 **검수 보고서 DOCX 저장**, **사진 포함 HTML 저장**, **인쇄 · PDF 저장**으로 결과를 남깁니다.

비교 실습에서는 **현재 검수 기록**의 확인 근거를 **영상 근거만 인정**으로 바꾸고 **기준 적용 · 재검토**를 누릅니다. 완료 후에도 배터리의 미확인 상태와 통과 취소가 기록됩니다. 이전 답변과 통과 신호는 그대로 보존됩니다. [화면별 조작 순서](docs/worker_monitor_v3/README.ko.md)에서 보류·수정·재진행을 확인하세요.

## 무엇이 실제로 동작하나요?

| 기능 | 동작 |
|---|---|
| 문서 정보 구축 | PDF.js로 실제 PDF 텍스트 추출, CSV 검사 기준 검증, SQLite 구성 |
| 작업자 설정 | 이름·사번·사진 등록, 교육용 화면 인증, 공정별 기준 연결 |
| 영상·설명 | 실제 영상 재생 + 미리 작성한 18개 세부 확인 이벤트 |
| 질문과 답변 | 수강생이 선택한 답변을 대상·질문·시각과 함께 기록 |
| 판정 | 영상 진행·관찰·답변·정책에 따른 검사, 단계 통과·보류·취소 기록 |
| 보고서 | 전자 조립은 사진 포함 DOCX·HTML 검수 보고서와 인쇄/PDF, 계측·기계 조립은 도면/사진 포함 HTML·검수조서·CSV |
| 저장·복원 | 같은 브라우저의 새로고침 복원, 작업자 기록 JSON 내보내기·가져오기 |

작업자 흐름의 **Agent 안내 듣기**는 브라우저 음성 출력을 사용합니다. 답변은 버튼 또는 텍스트로 입력하며 음성 인식 기능은 포함하지 않습니다. 강의용 예시는 실제 생산 승인이나 모델 정확도 평가가 아닙니다.

## 계측 판독 — 제품에서 검수조서까지

계측 실습은 가상 **다온정밀의 플랜지 부시**를 검사합니다. 제품과 도면은 강의를 위해 만든 일관된 예시입니다.

1. **표준형 / 정밀형** 제품을 고릅니다. 제품별 도면·개정·검사 대상·허용 범위를 불러옵니다.
2. 예제 SOP PDF와 CSV로 **검사 기준 불러오기 · 정보 구축**을 실행합니다. **검사 시작 준비**에서 A외경·B길이·C두께와 검사자·LOT를 확인한 뒤 **측정 기록 시작**을 누릅니다.
3. 계측 화면을 보고 A에 `26.30`, B에 `40.02`, 단위 `mm`를 직접 입력합니다. 기록 후 **모니터링에서 기록 확인**을 누르면 도면 위치와 검사표에 값이 기입됩니다. **B 측정 시작**, **C 측정 시작**으로 다음 작업자 화면을 엽니다.
4. C의 `5.?8 mm`에는 확정값을 넣지 않고 질문합니다. **질문 확인**을 누르고 값 `5.78`, 단위 `mm`를 입력한 뒤 **확인값 기록**을 누르면 두께 판정을 계산합니다.
5. **모니터링에서 기록 확인** → **검사 결과 검토**로 결과를 확인한 뒤 **검수조서 만들기**를 누릅니다. **검수조서 저장**으로 제품·도면·기준·측정값·질문/답변을 한 파일에 남깁니다.

표준형은 예시 확인 후3개 항목이 충족됩니다. 정밀형은 길이 허용 범위가 좁아40.02mm가 불일치입니다. 기준을 바꾸거나578mm처럼 잘못된 값을 입력해도 원래 숫자를 임의로 고치지 않습니다. 도면 원래 기준과 실습 중 바꾼 기준은 별도로 표시합니다.

## 추가 실습과 강사용 자료

이전 독립 계측 판독, 기계 조립, 오류 사례와 부품 교체 사례도 보존했습니다. 강사용 이전 계측 사진은 서로 다른 장비 사례이고, 새 플랜지 부시 실습은 같은 가상 제품을 일관되게 그린 강의용 도해입니다. 새 기계 조립은 4단계 WebM 영상을 재생하며, 이전 프레임 기반 실습은 강사용 경로에서 계속할 수 있습니다.

새 작업자 기록은 `dynin-seminar-worker-export-v1` 형식으로 저장합니다. 이전 `dynin-seminar-export-v1` 파일은 기존 경로로 복원하며 결과를 새 흐름으로 덮어쓰지 않습니다.

이전에 수집한 전자 조립 실제 모델 응답은 **강사용 참고 경로**로 남겨 두었습니다. 기본 실습에서는 불러오지 않습니다. 원본 요청·응답과 과거 검수는 [별도 기록](docs/recorded_electronics_v1/RESULTS.ko.md)에 있습니다.
