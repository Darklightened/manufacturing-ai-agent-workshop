제조 AI 실습 — Windows 오프라인 예비 실행팩

평소에는 강사가 안내한 웹 주소를 Chrome 또는 Edge로 엽니다.
이 ZIP은 인터넷 연결이 어려울 때 사용할 선택 사항입니다.
수강생의 사전 다운로드는 필수가 아닙니다.

실행
1. Windows 10/11 64비트 PC에서 ZIP 전체를 압축 해제합니다.
   ZIP 창 안에서 파일 하나만 실행하지 마세요.
2. 압축을 푼 폴더의 START_WINDOWS.cmd를 더블클릭합니다.
3. 잠시 후 브라우저가 열립니다. 실습 중 실행 창을 열어 두세요.
   자동으로 열리지 않으면 다음 주소를 Chrome 또는 Edge에 입력합니다.
   http://127.0.0.1:8922/
4. 끝나면 결과 문서를 저장하고 실행 창에서 Ctrl+C를 누르거나 창을 닫습니다.

Python은 이 ZIP에 포함되어 있습니다. 별도 설치, 관리자 권한,
API 키, 모델/GPU, 시작 시 다운로드가 필요하지 않습니다.
브라우저는 PC에 설치된 Chrome 또는 Edge를 사용합니다.
Windows 보안 정책으로 실행이 차단되면 기관 담당자에게 확인하세요.
실행 정책이나 방화벽을 바꾸지 않습니다.

저장과 재실행
- 같은 PC, 같은 브라우저 프로필, 같은 주소에서 진행 기록을 복원합니다.
- 실습 탭은 하나만 사용하세요. 같은 폴더를 다시 실행하면 기존 서버를 확인합니다.
- 온라인 주소, 기존 수동 실행의 8921번 주소, 이 8922번 주소는 저장 공간이 다릅니다.
  주소·PC·브라우저를 바꿀 때는 진행 내보내기/가져오기를 사용하세요.
- 브라우저 데이터 삭제 또는 시크릿 모드 종료 시 기록이 사라질 수 있습니다.
  완료한 검수조서와 진행 파일은 직접 저장해 주세요.
- 이 주소는 현재 PC에서만 열립니다. 다른 수강생 PC용 서버 주소가 아닙니다.

문제 해결
- 포트 사용 중: 다른 실습 폴더의 실행 창이나 해당 포트를 쓰는 프로그램을
  먼저 종료하세요. 저장 주소가 달라지지 않도록 포트를 자동 변경하지 않습니다.
- 파일 누락: START_WINDOWS.cmd, app, scripts, runtime이 같은 폴더에 있는지
  확인하고 ZIP 전체를 다시 압축 해제하세요.
- 실행 창을 닫은 뒤 브라우저만 남아 있으면 START_WINDOWS.cmd를 다시 실행하세요.
- 설치된 음성에 따라 안내 음성이 제공되지 않을 수 있습니다. 화면 안내는 유지됩니다.
- 파일 안의 외부 출처 링크와 공개 사이트/배포 링크는 인터넷이 필요할 수 있습니다.
  실습용 영상·문서·라이브러리는 이 실행팩 안에서 불러옵니다.

검수용 명령
  START_WINDOWS.cmd --no-browser
브라우저를 자동으로 열지 않고 같은 서버를 실행합니다.
--port는 진단용이며 포트 변경 시 브라우저 저장 공간도 달라집니다.
