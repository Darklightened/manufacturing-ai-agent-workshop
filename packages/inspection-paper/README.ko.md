# 검사 문서 및 도면 표시

이 모듈은 현재 검사 기록의 표시 양식만 담당합니다. 숫자 보정, 기준 완화, 자동 승인, 새 관찰 생성은 수행하지 않습니다.

- `engineeringDrawing({inspection, assessments, statuses, criteria, activeId, inspector, lot, showValues})`: 기존 `scenario.inspection`과 현재 판정에서 공학 도면 SVG 생성. A 외경, B 전체 길이, C 플랜지 두께의 도면 치수와 측정 기록을 구분해 표기. `statuses`는 미완료 재확인 요청 등 현재 상태를 반영하는 선택 인수.
- `formalInspectionDocument({scenario, session, summary, inspection})`: `Core.summarize` 결과를 받아 독립 HTML 생성. 계측 4개 절, 조립 3개 절. 표 중심 검사 결과, 공학 도면, 증거 사진, 질문·답변, 이전 판정·기준 변경·안내 이력, 미서명 결재란 포함.
- `inspectionPaperCss`: 단독 표시·인쇄용 스타일. A4 페이지와 한글 글꼴 연결. 다운로드 시 기존 앱의 이미지·글꼴 내장 절차 적용.

## 표시 원칙

도면의 공칭 치수는 원래 입력 자료를 사용합니다. B의 공칭 40.00과 측정 40.02, C의 공칭 5.80과 확인 5.78을 서로 덮어쓰지 않습니다. 미확인 상태는 이전에 유효한 값이 있어도 적합으로 표시하지 않습니다. 변경된 허용 범위는 원래 도면 범위와 함께 별도로 기록합니다. 입력 수치는 반올림하거나 578을5.78로 변경하지 않습니다.

문서의 발행일과 검사 발생 시각은 구별합니다. 계약·납기·금액·서명 등 제공되지 않은 내용을 만들지 않습니다. 출처와 전체 원장은 접을 수 있는 상세 항목으로 보존합니다. UI에 보이는 결과를 실제 제품 승인이나 모델의 실측 성능으로 해석하지 않습니다.

## 검증

```sh
node --test packages/inspection-paper/paper.test.mjs
```

7개 검증: 공칭·측정값 구분, 미확인 상태 유지, XML 이스케이프, 사진·원시 표시·전체 이력 보존, 규격 이탈·재확인, 메모와 수치 동시 표시, 기계 조립 부정 답변과4장사진. 실제 브라우저에서 한글 글꼴·사진을 로드하고 표준 계측 보고서가4쪽 A4로 출력되는 것을 확인했습니다. 실제 모델 호출 및 물리적 계측 정확도 검증이 아닙니다.
