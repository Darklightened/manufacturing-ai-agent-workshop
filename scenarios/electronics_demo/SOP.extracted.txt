1. 준비할 자료와 부품
베이스 보드, 연결 부품, 스위치 S1·S2, 모터, 램프 L1, 프로펠러, 배터리 홀더, 배터리 2개, 작업지시서.
이 키트의 조립은 부품을 손으로 결합합니다. 영상에 없는 공구나 측정값은 추가하지 않습니다.
2. 작업 순서
task_id: preparation
1. 부품과 작업 준비
필요 부품과 지시서를 펼치고 작업할 보드 1개를 지정합니다.
task_id: circuit
2. 회로 연결
배터리 홀더–S1–모터를 연결하고, S2와 L1의 병렬 연결을 포함해 지시서 순서로 회로를 구성합니다.
task_id: propeller
3. 프로펠러 장착
프로펠러를 모터 축에 장착합니다. 장착 중 상태와 장착 완료 기록은 구분합니다.
task_id: battery
4. 배터리 삽입
배터리 두 개를 넣고 홀더의 + / − 표시와 방향이 맞는지 확인합니다.
task_id: switch
5. 스위치 확인
S1을 확인한 후 S2를 확인합니다. 이 수업의 순서 완료 사건은 미리 작성한 예시입니다.
task_id: final
6. 최종 외관 기록
전체 보드의 최종 외관 사진을 남기고 모든 검사 항목과 작업자 답변을 함께 검토합니다.

검사 기준과 확인 처리
작업번호 DEMO‑001 · 바람빛 회로 키트 · 강의용 예시
3. 여섯 가지 검사 기준
E‑PREP | 보드·연결 부품·모터·프로펠러·배터리·지시서 준비
확인 방법: 해당 단계의 예시 관찰과 사진을 기록합니다.
E‑CONNECTION | 작업지시서에 따른 회로 연결 완료
확인 방법: 해당 단계의 예시 관찰과 사진을 기록합니다.
E‑PROPELLER | 프로펠러가 모터 축에 장착됨
확인 방법: 해당 단계의 예시 관찰과 사진을 기록합니다.
E‑BATTERY | 배터리 두 개의 방향이 홀더 표시와 일치
확인 방법: 방향이 보이지 않으면 작업자에게 질문합니다. 긍정 확인을 별도 근거로 기록합니다.
E‑SWITCH | S1 확인 후 S2 확인 순서 준수
확인 방법: 해당 단계의 예시 관찰과 사진을 기록합니다.
E‑FINAL | 조립 완료 외관 사진과 확인 기록 확보
확인 방법: 해당 단계의 예시 관찰과 사진을 기록합니다.
4. 배터리 확인 질문
질문: 배터리 두 개의 방향이 홀더의 + / − 표시와 맞나요?
답변 예: 방향을 확인했습니다. → 작업자 확인 근거로 충족
답변 예: 반대로 들어가 있습니다. → 불일치 기록
답변 없음 / 확인할 수 없음 → 보류 유지
기본 정책은 작업자 확인을 인정합니다. 실습 중 사진 증거만 인정하도록 바꾸면 같은 답변이 있어도 보류가 됩니다.
5. 산출물과 완료 조건
검수조서: 여섯 기준의 판정, 근거 유형, 질문·답변, 사진, 변경한 확인 정책.
작업 보고서: 작업 순서, 주요 장면, 미확인 항목, 최종 판정 및 이력.
기본 예시는 배터리 확인 전 충족 5 / 보류 1, 긍정 확인 후 충족 6입니다. 작업 진행이 끝나도 미확인 항목을 자동으로 통
과시키지 않습니다.
