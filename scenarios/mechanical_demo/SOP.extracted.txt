강의용 가상 회사 문서 · 공개 영상에 맞춘 외관 확인 예시
company_id: edu-daon-mechanical
process_id: MECH-DEMO-001
1. 대상과 검사 범위
한 개의 차체, 앞쪽 브래킷, 두 축의 네 바퀴를 동일 작업 대상으로 기록합니다. 원본 영상의 시각을 유지하여 네 단계로 
재생합니다.
외관·배치와 작업자 확인만 다룹니다. 체결 토크, 고정 강도, 구동 성능 및 생산 안전 승인은 판정하지 않습니다.
2. 작업 순서
task_id: chassis
1. 차체 연결 | 원본 0~70초
두 긴 차체 부재를 연결합니다. 단계 마지막에는 손을 뗀 차체 연결 상태를 확인합니다.
task_id: bracket
2. 브래킷 배치 | 원본 70~90초
앞쪽 브래킷을 놓고 연결합니다. 브래킷의 배치는 보이지만 안쪽 연결 핀은 손에 가려져 직접 확인이 필요합니다.
task_id: axle
3. 바퀴 축 조립 | 원본 90~178초
두 축에 바퀴를 차례로 배치합니다. 마지막 장면에서 양쪽 축의 네 바퀴가 보이는지만 확인합니다.
task_id: final
4. 최종 외관 기록 | 원본 178~184.4초
손을 뗀 완성 외관을 기록합니다. 앞 단계의 작업자 확인과 검사 이력을 함께 검토합니다.

확인 방법: 단계 끝의 공개 영상 장면과 예시 관찰을 기록합니다.
MD‑BRACKET | 전방 브래킷이 차체 앞쪽에 놓인 상태
확인 방법: 단계 끝의 공개 영상 장면과 예시 관찰을 기록합니다.
MD‑PIN | 가려진 브래킷 안쪽 연결 핀의 삽입 상태 확인
확인 방법: 가려진 핀은 작업자 답변을 구분하여 기록합니다.
MD‑AXLE‑1 | 한쪽 축의 양쪽 바퀴가 배치된 외관
확인 방법: 단계 끝의 공개 영상 장면과 예시 관찰을 기록합니다.
MD‑AXLE‑2 | 다른 축의 양쪽 바퀴가 배치된 외관
확인 방법: 단계 끝의 공개 영상 장면과 예시 관찰을 기록합니다.
MD‑FINAL | 차체·브래킷·네 바퀴를 포함한 최종 외관 사진 기록
확인 방법: 단계 끝의 공개 영상 장면과 예시 관찰을 기록합니다.
3. 브래킷 연결 핀 질문
손에 가린 브래킷 안쪽 연결 핀이 제자리에 끼워졌나요? 직접 확인한 결과를 알려 주세요.
제자리에 끼운 것을 확인 → 작업자 확인으로 충족. 제대로 끼워지지 않음 → 불일치. 확인 불가 또는 답변 없음 → 보류.
이전 답변은 삭제하지 않습니다. 재확인할 때 새 질문과 답변을 기록합니다. 영상 근거만 인정하는 정책으로 바꾸면 가려
진 핀은 다시 보류됩니다.
4. 산출물과 출처
