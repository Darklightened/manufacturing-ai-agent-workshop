# 전자 조립 실습: 바람빛 회로 키트

가상의 다온에듀테크에서 회로 키트 한 세트를 조립하는 실습입니다. 회사 정보를 구축한 뒤 작업자가 태블릿에서 등록·인증·공정 선택을 완료하고, 영상에 맞춰 단계별 검사를 진행합니다. Agent가 확인하지 못한 부분은 작업자가 답하며, 마지막에 실제 DOCX 검수 보고서를 저장합니다.

**v0.6.0 작업자 흐름입니다.** 기존 121장 슬라이드는 아직 이전 화면입니다. [작업자 화면별 안내](worker_flow_v1/README.ko.md)에 전체 조작 순서를 정리했습니다.

공개 영상과 미리 작성한 강의용 관찰을 사용합니다. GPU·API 없이 실행하며, 영상 재생과 조건 비교, 단계 통과·보류, 작업자 답변, 보고서 생성은 브라우저에서 실제로 처리합니다. 얼굴 인식이나 실시간 모델 추론은 수행하지 않습니다.

## 실습 자료

- [작업지시서·조립 절차 PDF](../scenarios/electronics_demo/SOP.pdf): 가상 회사, 작업번호, 부품 목록, 여섯 작업과 원본 검사 기준.
- [검사 기준 CSV](../scenarios/electronics_demo/criteria.csv): 여섯 기준의 ID·작업·대상·확인 정책. 세부 확인 항목 18개는 이 원본 기준에 연결한 강의용 확장 항목.
- [기존 관찰 시나리오](../scenarios/electronics_demo/scenario.json): 이전 관찰 지점과 출처를 보존한 자료.
- [새 단계별 검사 계획](../packages/worker-flow/plan.mjs): 여섯 영상 구간, 18개 세부 항목, 근거 사진과 확인 질문.
- [공개 원본 영상](../data/source_pack/electronics/S1790005/S1790005.mp4): EgoOops의 전자 회로 조립 영상. 실습 화면은 브라우저 호환을 위한 WebM 변환본 사용.

PDF와 CSV를 실제로 읽어 회사·공정·작업 순서·검사 기준을 SQLite로 구성합니다. 도면 해석과 세부 검사 이벤트는 수업을 위해 작성한 예시이며 임의 문서의 LLM 분석이나 실제 품질 판정 결과가 아닙니다.

## 기본 진행

1. 회사 폴더를 업로드하고 파일 선택·미리보기 → **선택 자료로 정보 구축**을 진행합니다.
2. 배터리 기준을 **배터리 삽입(battery)**에 연결해 저장하고 온톨로지를 확인합니다. **자료 구축 완료 · 작업 설정으로**를 누릅니다.
3. 작업자 **김민수 / DA-024**와 사진 또는 예시 프로필을 등록합니다. **등록하고 인증으로**를 누릅니다.
4. 등록 정보 확인에 체크하고 **6421**을 입력한 뒤 **인증 확인**을 누릅니다.
5. **바람빛 회로 키트 · 전자 조립** 선택 → **작업 시작 · 영상 연결** → **영상 재생**을 누릅니다.
6. 영상 진행에 따라 확인되는 세부 항목을 봅니다. 단계 종료와 세 항목 충족 후 **Agent 통과 신호**가 기록되면 **다음 작업 시작**을 누릅니다.
7. 배터리 질문에서 **질문 확인** 후 답변합니다. 방향이 반대이거나 확인하지 못했으면 보류되며, 방향 확인 답변은 원시 영상 관찰과 별도로 저장됩니다.
8. 여섯 단계·18개 항목을 마친 뒤 **작업 완료 · 결과 보기** → **검수 보고서 보기**에서 DOCX·사진 포함 HTML·인쇄/PDF를 저장합니다.

첫 화면의 인증은 강의용 등록 정보 확인입니다. 실제 계정 인증은 아닙니다. 영상은 단계 중 계속 재생되고 경계에서 멈춥니다. 재생 속도는 1배·2배·4배를 선택합니다. 미시청 구간을 건너뛰어 검사 완료로 처리하지 않습니다.

## 같은 장면으로 결과 바꾸기

| 조건 | 단계 진행과 결과 |
|---|---|
| 배터리 질문에 답하지 않음 | 배터리 단계 보류, 이후 단계 진입 불가 |
| 방향 확인 답변 + 기본 정책 | 배터리 통과 후 이후 두 단계 진행 가능 |
| 반대로 들어갔다는 답변 | 불일치와 답변 기록, 다음 단계 보류 |
| 보류 후 방향을 수정하고 긍정 답변 | 이전 답변을 보존하고 배터리 재판정·통과 |
| 완료 후 영상 근거만 인정하도록 변경 | 배터리 확인 필요, 이후 통과 및 전체 완료 취소 |
| 작업자 확인을 다시 인정 | 원시 관찰·답변을 유지한 채 재판정, 이후 단계 진행 재확인 |

정책 비교는 **현재 검수 기록**의 **검사 기준 비교**에서 확인 근거를 선택한 뒤 **기준 적용 · 재검토**로 실행합니다. 취소된 과거 통과 신호도 이력에 남습니다. 수치·단위·허용 범위 변경은 별도의 계측 실습에서 다룹니다.

## 보고서와 진행 파일

검수 보고서는 A4 표 형식으로 회사·제품·작업자·기준 버전, 단계별 결과, 18개 세부 항목, 최초 관찰과 현재 판정, 질문·답변, Agent 신호와 증거 사진을 담습니다. 입력하지 않은 LOT는 미입력으로 남고 실제 검토·승인 서명은 생성하지 않습니다. 미완료 상태의 보고서는 보류로 표시합니다.

**진행 내보내기**는 `dynin-seminar-worker-export-v1` 형식의 작업자 기록 JSON을 저장합니다. 같은 브라우저에서는 새로고침으로 복원하며, 다른 환경에서는 **진행 가져오기**로 이어갑니다. 회사 자료 원본 파일은 진행 JSON에 포함하지 않습니다. 사진을 등록했다면 작업자 사진·이름·사번은 JSON에 포함될 수 있습니다.

**Agent 안내 듣기**는 브라우저 음성 출력이며 자동 음성 인식은 아닙니다. 답변은 버튼으로 입력합니다. 강의 PC의 영상과 한국어 음성 출력을 사전에 확인하세요.

## 기존 자료와 재생성

기존 `electronics` 팩과 저장된 Qwen 응답은 별도의 강사용 비교 자료로 보존합니다. 기본 실습의 예시 관찰은 `authored_demo`, 기존 작성 이벤트는 `authored_fixture`, 실제 응답 재생은 `recorded` 경로입니다. 서로의 결과를 덮어쓰지 않습니다.

```sh
python scripts/prepare_electronics_demo.py
```

교재를 재생성하는 개발 환경에는 PyMuPDF와 fontTools가 필요합니다. 수강생의 브라우저 실행에는 이 Python 패키지가 필요하지 않습니다.

이 명령은 기존 전자 조립 예시 문서와 실습 목록을 재생성하는 개발 도구입니다. 새 작업자 UI·검사 계획·WebM 변환본을 생성하는 명령은 아닙니다. 기존 전자 조립 문서·시나리오·저장 응답의 바이트가 유지되는지 함께 검사합니다. 원본 자료를 다시 가져오는 `prepare_data.py`는 기존 시나리오를 생성하는 다른 경로이므로 새 예시 작성에 사용하지 않습니다.
