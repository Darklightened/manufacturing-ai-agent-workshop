# 전자 조립 실습: 바람빛 회로 키트

가상의 다온에듀테크에서 회로 키트 한 세트를 조립하는 실습입니다. 수강생은 준비된 자료로 회사 정보를 만들고, 작업을 따라가다가 배터리 방향 질문에 답한 뒤 검수조서와 보고서를 저장합니다. 자료 구축은 폴더 등록·파일 검토·DB 수정·온톨로지 확인으로 진행하며, 이후 조립 시연과 연결합니다.

**공개 영상과 미리 작성한 강의용 관찰을 사용합니다.** 실제 모델 결과를 흉내 낸 실행 기록은 만들지 않습니다. GPU·API 없이 실행되며, 수강생 답변과 확인 정책에 따른 판정·보고서 변경은 브라우저가 실제로 계산합니다.

[회사별 입력 자료 ZIP](../assets/company-materials/company-practice-materials.zip) · [새 회사 자료 구축 안내](company_build_v2/README.ko.md)

## 실습 자료

- [작업지시서·조립 절차 PDF](../scenarios/electronics_demo/SOP.pdf): 가상 회사, 작업번호, 부품 목록, 여섯 작업, 확인 방법과 산출물.
- [검사 기준 CSV](../scenarios/electronics_demo/criteria.csv): 여섯 기준의 ID·작업·대상·확인 정책.
- [실습 설정](../scenarios/electronics_demo/scenario.json): 원본 장면과 강의용 사건의 연결.
- [공개 원본 영상](../data/source_pack/electronics/S1790005/S1790005.mp4): EgoOops의 전자 회로 조립 영상.

PDF의 회사·공정·작업 순서와 CSV의 검사 기준을 실제로 읽어 SQLite로 구성합니다. 임의 문서를 이해하는 LLM 문서 분석은 이 수업의 범위에 포함하지 않습니다.

## 기본 진행

1. **전자 조립 실습 시작** → 회사 자료 ZIP 압축 해제 → **폴더 전체 업로드**에서 다온에듀테크 선택 → 파일 선택·미리보기 → **선택 자료로 정보 구축**을 누릅니다.
2. DB 초안에서 배터리 검사 항목을 **배터리 삽입(battery)** 작업으로 수정하고 저장합니다. **검토 완료 · 온톨로지 보기**에서 여섯 작업과 기준을 확인한 뒤 **자료 구축 완료 · 작업 설정으로**를 누릅니다.
3. 준비된 작업 지시와 작업 순서를 확인한 뒤 **작업 시작하기**를 누릅니다. 작업 지시 번호는 교재에 정해져 있으며 이 화면에 작업자 이름을 입력하는 칸은 없습니다.
4. **준비 장면 확인하기**, 이후 **다음 장면 확인하기**로 순서대로 진행합니다. 프로펠러 장착 중에는 아직 완료 판정을 내리지 않습니다.
5. 배터리 장면에서 **질문 확인**을 먼저 누른 뒤 **방향을 확인했습니다**라고 답합니다. 답변은 예시 관찰과 구분해 기록됩니다.
6. 끝까지 진행하여 **충족 6 / 확인 필요 0**을 확인합니다. **결과 확인 · 보고서 만들기** → **보고서 만들기**를 누르고 **사진 포함 HTML 저장**과 **검수조서 저장**으로 결과를 저장합니다.

| 원본 영상 시각 | 작업 | 강의용 사건 | 기록되는 변화 |
|---|---|---|---|
| 00:00.500 | 부품과 작업 준비 | 준비 완료 | 준비 기준 충족 |
| 01:16.731 | 회로 연결 | 지시서대로 연결 완료한 것으로 설정 | 회로 기준 충족 |
| 01:29.659 | 프로펠러 장착 | 장착 진행 중 | 진행 기록만 저장 |
| 01:39.726 | 배터리 삽입 | 프로펠러 장착 완료, 배터리 방향 가림 | 프로펠러 충족 + 배터리 확인 질문 |
| 01:53.870 | 스위치 확인 | S1 다음 S2 확인한 것으로 설정 | 순서 기준 충족 |
| 02:00.021 | 최종 외관 | 최종 사진 저장 | 외관 기록 충족, 남은 보류 유지 |

시각은 실제 원본 영상 위치입니다. 회로 연결 완료와 스위치 순서 완료는 이해하기 쉬운 흐름을 위해 작성한 사건이며, 해당 정지화면만으로 증명한 사실이 아닙니다. 배터리 방향에 대한 작업자 답변도 실습 참가자의 진술입니다.

## 같은 장면으로 결과 바꾸기

| 실습 조건 | 마지막 결과 | 배울 내용 |
|---|---|---|
| 배터리 질문에 답하지 않음 | 충족 5 / 보류 1 | 작업이 끝났어도 미확인 항목은 남음 |
| 방향 확인 답변 + 기본 정책 | 충족 6 / 보류 0 | 작업자 확인이 허용된 항목은 답변을 별도 근거로 인정 |
| 반대로 들어갔다는 답변 | 충족 5 / 불일치 1 | 긍정 답변만 준비된 고정 시연이 아님 |
| 긍정 답변 후 사진 증거만 인정하도록 변경 | 충족 5 / 보류 1 | 같은 관찰·답변도 검사 정책에 따라 판정이 달라짐 |
| 다시 작업자 확인을 인정 | 충족 6 / 보류 0 | 원래 관찰과 답변을 보존한 채 정책으로 재판정 |

이 예시는 수치 측정을 하지 않습니다. 숫자·단위·허용 범위를 바꾸는 실습은 별도의 계측 판독 팩에서 다룹니다.

답변을 바꾸려면 결과 화면의 배터리 항목에서 **답변 다시 확인하기**를 누릅니다. 돌아온 질문 화면에서 **질문 확인**을 다시 누른 뒤 새 답변을 선택하세요. 이전 답변은 이력에 남습니다. 정책 비교는 같은 배터리 항목의 **시각 증거만 인정** 또는 **작업자 직접 확인도 인정**을 선택하고 **기준 적용 · 재판정**을 눌러 실행합니다.

## 보고서에서 확인할 것

예시 관찰, 최종 적용 판정, 질문과 답변, 확인 정책, 주요 사진, 판정 변경 이력을 함께 확인합니다. 보고서의 충족은 이 강의의 예시 기준에 대한 결과이며, 실제 원본 작업의 산업용 검사 승인이나 모델 정확도 지표가 아닙니다.

음성 버튼은 브라우저의 읽어 주기 기능입니다. 작업자 입력은 버튼이나 텍스트로 수행하며, 자동 음성 인식이 연결된 것처럼 표시하지 않습니다. 강의 전에 사용 PC의 한국어 음성과 영상 재생을 확인하세요.

## 기존 자료와 재생성

기존 `electronics` 팩과 저장된 Qwen 응답은 별도의 강사용 비교 자료로 보존합니다. 기본 실습의 예시 관찰은 `authored_demo`, 기존 작성 이벤트는 `authored_fixture`, 실제 응답 재생은 `recorded` 경로입니다. 서로의 결과를 덮어쓰지 않습니다.

```sh
python scripts/prepare_electronics_demo.py
```

교재를 재생성하는 개발 환경에는 PyMuPDF와 fontTools가 필요합니다. 수강생의 브라우저 실행에는 이 Python 패키지가 필요하지 않습니다.

이 명령은 새 예시 폴더와 실습 목록만 갱신합니다. 기존 전자 조립 문서·시나리오·저장 응답의 바이트가 유지되는지 함께 검사합니다. 원본 자료를 다시 가져오는 `prepare_data.py`는 기존 시나리오를 생성하는 다른 경로이므로 새 예시 작성에 사용하지 않습니다.
