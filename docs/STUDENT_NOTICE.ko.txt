[제조 AI Agent 실습 사전 안내]

노트북(또는 PC)과 충전기를 준비해 주세요. Chrome 또는 Edge를 사용합니다.
평소에는 아래 실습 링크만 열면 됩니다. 백업 파일을 미리 다운로드할 필요는 없습니다.

실습 주소
https://darklightened.github.io/manufacturing-ai-agent-workshop/

실습 1에서는 수업 중 회사 입력 자료 ZIP을 받아 압축을 풀고,
'폴더 전체 업로드'에서 '다온에듀테크' 폴더를 선택합니다.
다운로드 없이 시작하려면 화면의 '준비된 회사 자료로 시작'을 선택합니다.
회사 입력 자료는 업로드 연습용이며 앱 백업 파일과는 다릅니다.

자료 다운로드
https://darklightened.github.io/manufacturing-ai-agent-workshop/downloads.html
최신 슬라이드 PDF(155장)와 참고 자료는 선택 사항입니다.

웹 접속이 어려울 때만 Windows 실행 ZIP을 선택할 수 있습니다.
Windows 10/11 x64에서 workshop-windows.zip을 모두 압축 해제한 뒤
DyninWorkshop 폴더의 START_WINDOWS.cmd를 더블클릭합니다.
런타임이 포함되어 있어 별도 Python 설치는 필요 없습니다.
브라우저가 열리지 않으면 http://127.0.0.1:8922/에 접속합니다.
온라인과 로컬 주소 사이의 진행 이동은 JSON 내보내기·가져오기로 합니다.

GitHub 로그인, API 키, 모델·GPU, 마이크는 필요하지 않습니다.
실습 앱은 한 탭만 열어 주세요. 수업 종료 전 검수조서·보고서와 진행 JSON을 저장하고 강사가 안내하는 곳에 제출합니다.
