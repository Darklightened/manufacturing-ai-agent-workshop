| 항목 | 안내 |

회사 입력 ZIP은 문서 선택·미리보기와 **폴더 전체 업로드**를 연습하는 입력 자료입니다. 앱을 실행하는 Windows ZIP과 용도가 다릅니다. 수업 중 업로드를 선택하면 **선택 자료로 정보 구축** → 배터리 기준을 **배터리 삽입(battery)** 작업으로 수정·저장 → **검토 완료 · 온톨로지 보기** → **자료 구축 완료 · 작업 설정으로** 순서로 진행합니다. [회사 자료 구축 안내](company_build_v2/README.ko.md).

## 3. 강의 전 리허설

- 실제 강의 PC와 강의실 네트워크에서 실습 링크·자료실·현재 슬라이드 확인.
- 전자 조립에서 회사 자료 검토를 완료하고 작업자 등록·화면 인증·영상 재생·질문 답변·모니터링·보고서 저장까지 확인.
- 계측 표준형에 A=26.30 mm, B=40.02 mm를 기록하고 C 질문에 5.78 mm 답변: 충족 3개 확인. 정밀형은 같은 값에서 B 불일치 확인.
- 기계 조립의 영상 단계·가려진 핀 질문·작업 안내·결과 저장 확인.
- 진행 JSON을 내보낸 뒤 가져오기로 제품·값·판정·답변이 복원되는지 확인.
- 강사 음성 재생과 화면 질문 확인. 수강생은 버튼·텍스트로 답변 가능.
- 브라우저의 실습 앱 탭은 한 개만 사용. 슬라이드·자료실은 별도 탭으로 열기.
- 수강생 결과 제출처와 파일명 규칙 정하기. 사이트에 강사용 자동 수집·진도 대시보드는 없음.

## 4. 필요할 때만 Windows ZIP 실행

인터넷 연결이 정상일 때는 웹 링크로 계속 사용합니다. 웹 접속이 어려워 Windows ZIP을 선택하는 경우 아래 순서로 실행합니다. 연결이 끊겨 다운로드할 수 없으면 강사가 이미 가진 ZIP을 USB 등으로 전달할 수 있습니다.

```text
1) workshop-windows.zip 다운로드 후 전체 압축 해제
2) DyninWorkshop 폴더 열기
3) START_WINDOWS.cmd 더블클릭
4) 열린 브라우저에서 실습 진행
   브라우저가 열리지 않으면 http://127.0.0.1:8922/ 접속
5) 실습 중 실행 창 유지, 종료할 때 창 닫기
```

Windows 10/11 x64와 Chrome 또는 Edge를 사용합니다. ZIP 안에서 바로 실행하지 말고 전체 압축을 푼 뒤 시작합니다. 런타임이 함께 들어 있어 Python을 따로 설치하지 않습니다. `index.html`을 직접 여는 대신 `START_WINDOWS.cmd`로 시작합니다.

`127.0.0.1:8922`는 실행한 PC에서만 열리는 주소입니다. 다른 수강생 PC에서는 각자 ZIP을 실행해야 합니다. 온라인 주소·다른 웹 주소·로컬 주소는 브라우저 저장 영역이 다릅니다. **주소를 바꾸기 전에 진행 JSON을 내보내고, 새 주소에서 가져오기**로 옮깁니다. 저장한 개별 HTML 보고서는 직접 열 수 있으며, 보고서 파일과 진행 JSON은 용도가 다릅니다.

## 5. 30명 수업 운영과 검증 범위

**30명 수업은 각자의 브라우저에서 처리하는 구조를 기준으로 계획합니다.** 웹 서버는 파일을 전달하고 PDF 처리·DB 구성·판정·보고서는 각 PC에서 실행합니다. 공용 모델 서버나 서버 DB의 처리 순서를 기다리는 구조가 아니며 연구용 GPU 서버가 필요하지 않습니다.

기존 검수에서는 한 로컬 호스트에서 20개의 독립 브라우저 세션을 동시에 실행해 전자 긍정·반대, 계측 표준형·정밀형, 보고서 저장과 새로고침 복원을 확인했습니다. [당시 검수 요약](CLASSROOM_CHECK.json). 이는 당시 앱의 세션·저장 분리 검증이며, 현재 버전의 30명 동시 사용, 30대 실물 PC, 공개 사이트 처리량 또는 강의실 Wi-Fi 검증은 아닙니다.

실제 수업의 첫 로딩과 영상 재생 속도는 강의실 네트워크와 각 PC 성능의 영향을 받습니다. 수업 시작 전 실제 환경에서 접속·영상 재생을 확인하고, 지연 시 몇 명씩 차례로 접속하거나 필요한 PC에서 선택 Windows ZIP을 사용합니다. 사전 백업 다운로드를 수강 조건으로 두지 않습니다.

## 6. 개인 저장과 결과 제출

- 서로 다른 PC·브라우저 프로필의 진행 기록은 분리. 한 사람의 답변이나 기준 변경이 다른 사람의 판정을 바꾸지 않음.
- 같은 브라우저 프로필·같은 실습 주소의 여러 앱 탭은 저장 영역을 공유. 실습 앱 탭은 한 개만 사용.
- 진행은 브라우저 IndexedDB에 저장. 사이트 데이터 삭제, 시크릿 창 종료, PC·주소 변경에 대비해 진행 JSON 내보내기.
- 주소를 바꿀 때는 진행 JSON을 새 주소에서 가져오기. 온라인에서 하던 진행이 로컬 주소에 자동으로 나타나지는 않음.
- 실습별 검수조서·보고서와 진행 JSON 저장. 예: 03_실습1_검수보고서.docx, 03_실습1_진행.json.
- 개인 결과는 서버에 자동 제출되지 않음. 강사가 정한 제출처에 직접 업로드.
