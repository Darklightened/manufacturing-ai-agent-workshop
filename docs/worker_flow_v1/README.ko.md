# 실습 1: 작업자 등록과 단계별 조립 검수

v0.6.0 작업자 흐름입니다. 회사 자료 구축을 마친 다음, 수강생이 직접 작업자가 되어 태블릿 등록부터 조립 검수와 보고서 저장까지 진행합니다. 기존 121장 설명 슬라이드는 이전 화면을 유지하고 있습니다.

전체 순서는 **회사 자료 구축 → 작업자 등록 → 화면 인증 → 공정 선택 → 영상 재생과 단계별 검사 → 작업자 확인 → 검수 보고서**입니다.

## 시작 전 준비

회사 자료 구축은 앞 실습과 같습니다. [회사별 입력 자료 ZIP](../../assets/company-materials/company-practice-materials.zip)을 풀어 다온에듀테크 폴더를 업로드하고, 필요한 파일 선택과 미리보기를 진행합니다. **선택 자료로 정보 구축** 후 DB 초안의 배터리 기준을 **배터리 삽입(battery)** 작업으로 수정합니다. **검토 완료 · 온톨로지 보기** → **자료 구축 완료 · 작업 설정으로**를 누릅니다.

이번 공정은 **다온에듀테크의 바람빛 회로 키트 조립**이며 작업 지시는 `DEMO-001`입니다. 원문에서 구축한 여섯 검사 기준에 단계별 세부 확인 항목 세 개씩을 연결했습니다. 총 여섯 단계, 18개 세부 항목입니다. 세부 항목은 수업을 위해 추가한 검사 예시이며 회사 원문에 새로 추출된 내용으로 표시하지 않습니다.

## 1. 작업자 등록

태블릿 화면에서 이름과 사번을 입력합니다. 예시는 **김민수 / DA-024**입니다. 수강생 본인 이름 대신 예시 이름을 사용해도 됩니다.

- **사진 등록**: 컴퓨터의 사진을 선택합니다. 지원 기기에서는 촬영 선택 화면이 열릴 수 있습니다.
- **예시 프로필 사용**: 개인 사진 없이 준비된 프로필로 진행합니다.
- **등록하고 인증으로**: 이름·사번·사진 선택을 저장하고 다음 화면으로 이동합니다.

사진은 브라우저 안에서 처리합니다. 얼굴 분석이나 외부 서버 전송은 하지 않습니다. 진행 JSON에는 등록한 사진·이름·사번도 포함될 수 있으므로 수업 제출용 기록은 예시 프로필로 진행하면 편리합니다.

## 2. 화면 인증

등록한 사진, 이름, 사번을 확인합니다. **등록된 이름과 사번을 확인했습니다**에 체크하고, 사원증 예시에 표시된 번호 **6421**을 입력한 뒤 **인증 확인**을 누릅니다.

체크하지 않거나 다른 번호를 입력하면 다음 화면으로 넘어가지 않습니다. 이 절차는 작업 시작 시 등록 정보를 대조하는 **강의용 화면 인증**입니다. 실제 계정 로그인, 얼굴 인식 또는 보안 인증이 아닙니다.

## 3. 공정 선택

**진행 공정**에서 **바람빛 회로 키트 · 전자 조립**을 선택합니다. 선택하면 작업 순서, 18개 세부 확인 항목, 원본 검사 기준 버전과 작업 지시를 불러옵니다. **작업 시작 · 영상 연결**을 누르면 작업 중 화면으로 이동합니다.

포장 공정은 이번 실습에 제공되지 않으므로 선택할 수 없습니다. 자료가 없는 공정을 같은 결과로 대신 처리하지 않습니다.

## 4. 영상에 맞춘 단계별 검사

**영상 재생**을 누릅니다. 스마트 글래스 입력 대신 공개 조립 영상이 계속 재생되며, 진행 막대와 현재 영상 시각이 함께 움직입니다. 재생 속도는 **1배 / 2배 / 4배** 중 선택할 수 있습니다. 기본은 2배입니다. 아직 보지 않은 구간을 건너뛰어 검사 완료로 처리하지 않습니다.

| 단계 | 원본 영상 구간 | 세부 확인 예시 | 다음 단계 조건 |
|---|---|---|---|
| 부품과 작업 준비 | 0:00–0:12 | 보드·지시서, 연결 부품·모터·프로펠러, 배터리·작업 공간 | 영상 구간 종료 + 3개 항목 충족 |
| 회로 연결 | 0:12–1:16.731 | 부품 배치, 연결 위치, 회로 연결 완료 | 영상 구간 종료 + 3개 항목 충족 |
| 프로펠러 장착 | 1:16.731–1:39.726 | 축 위치, 삽입 상태, 장착 완료 | 영상 구간 종료 + 3개 항목 충족 |
| 배터리 삽입 | 1:39.726–1:48 | 홀더, 두 개 삽입, + / − 방향 | 영상 구간 종료 + 방향 질문 해결 |
| 스위치 확인 | 1:48–1:56 | S1 위치, S1 이후 S2 순서, 점검 기록 | 영상 구간 종료 + 3개 항목 충족 |
| 최종 외관 기록 | 1:56–2:01 | 외관, 작업 대상 연결, 기록 확보 | 영상 구간 종료 + 전체 검사 충족 |

각 구간의 확인 시점에 도달하면 오른쪽 항목이 차례로 체크됩니다. 해당 단계가 끝나면 영상이 멈춥니다. 모든 요구 조건이 충족되면 **Agent 통과 신호**가 표시되고 아래 **Agent 신호 · 작업 이력**에도 통과 시각이 기록됩니다. 그때 **다음 작업 시작**을 누릅니다. 마지막 단계에서는 **작업 완료 · 결과 보기**로 결과 화면을 엽니다.

이 구간 구분과 체크 이벤트는 강의용으로 구성한 예시입니다. 원본 영상의 실제 AI 인식·품질 판정 결과가 아닙니다. 영상 재생, 상태 저장, 조건 비교와 다음 단계 허용은 브라우저에서 실제로 실행합니다. 영상이 재생되지 않으면 완료 처리를 하지 않습니다.

## 5. 배터리 방향 확인 요청

배터리 방향은 손과 홀더에 가려져 영상만으로 확인하지 못한 것으로 설정되어 있습니다. 이 항목은 자동으로 체크하지 않고 Agent가 작업자에게 질문합니다.

1. **질문 확인**을 누릅니다.
2. 실제로 확인했다고 가정한 결과에 맞춰 답합니다.
3. 답변과 판정 변화, 다음 단계 버튼을 확인합니다.

| 답변 | 검사 결과와 동작 |
|---|---|
| **방향을 확인했습니다** | 지정 항목의 작업자 확인을 인정하여 배터리 단계 통과 |
| **반대로 들어가 있습니다** | 불일치 기록, 다음 단계 보류 |
| **아직 확인할 수 없습니다** | 확인 필요 유지, 다음 단계 보류 |

보류 사례를 먼저 보고 싶으면 **반대로 들어가 있습니다**를 선택합니다. 방향을 수정하고 다시 확인했다고 가정한 후 **방향을 확인했습니다**로 답하면 통과할 수 있습니다. 최초 불일치 답변도 이력에 남습니다. 원래 영상 관찰의 ‘확인 불가’를 지우거나 ‘영상으로 확인함’으로 바꾸지 않습니다.

**Agent 안내 듣기**를 켜면 브라우저의 음성 출력으로 안내를 들을 수 있습니다. 실제 음성 인식은 연결하지 않으며 답변은 화면 버튼으로 입력합니다. 강의 PC의 한국어 음성 출력 여부는 시작 전에 확인합니다.

## 6. 검사 기준을 바꾸어 비교

**현재 검수 기록** 또는 완료 후 결과 화면에서 **검사 기준 비교**를 엽니다.

- **작업자 확인도 인정**: 지정된 배터리 방향 항목에 작업자 답변을 근거로 인정합니다.
- **영상 근거만 인정**: 같은 긍정 답변이 있어도 영상에서 보이지 않은 방향 항목은 확인 필요로 남습니다.

선택 후 **기준 적용 · 재검토**를 누릅니다. 완료된 작업에서 영상 근거만 인정하도록 바꾸면 전체 완료가 취소되고 배터리 단계로 돌아갑니다. 이전 통과 신호와 답변은 삭제하지 않고 취소·보류 이력을 추가합니다. 작업자 확인을 다시 인정해도 이후 단계가 즉시 완료된 것처럼 표시하지 않습니다. **작업 화면으로** 돌아가 단계별 진행을 다시 확인합니다.

## 7. 검수 보고서 저장

결과 화면의 **검수 보고서 보기**를 누릅니다. 미완료 상태에서도 현재까지의 기록을 보류 보고서로 확인할 수 있습니다.

- **검수 보고서 DOCX 저장**: Word에서 편집 가능한 실제 DOCX 문서입니다.
- **사진 포함 HTML 저장**: 증거 사진과 한글 글꼴을 포함한 독립 문서입니다.
- **인쇄 · PDF 저장**: 브라우저의 인쇄 화면에서 A4로 저장합니다.

보고서에는 회사·제품·작업 지시·작업자·기준 버전, 단계별 통과 결과, 18개 검사 항목, 최초 관찰과 현재 판정, 질문과 답변 이력, Agent의 통과·보류·취소 신호, 공정별 증거 사진이 들어갑니다. 증거 사진의 원본 시각과 체크가 기록된 시각은 구분합니다. LOT 등 입력하지 않은 정보는 미입력으로 남고, 검토자·승인자 서명은 자동 생성하지 않습니다.

## 8. 저장과 이어 하기

같은 브라우저에서 새로고침하면 등록 정보와 진행 기록을 복원합니다. 한 프로필에서는 실습 탭 하나를 사용합니다. 다른 PC로 옮기려면 상단 **진행 내보내기**로 `electronics-worker-session.json`을 저장하고 새 환경에서 **진행 가져오기**를 사용합니다.

새 작업자 흐름의 JSON 형식은 `dynin-seminar-worker-export-v1`입니다. 회사 기준과 작업 명령을 다시 검증한 뒤 복원합니다. 회사 자료 구축의 검토 이력은 포함하지만 업로드한 회사 원본 파일 자체는 포함하지 않습니다. 원문 파일 미리보기가 다시 필요하면 자료를 별도로 준비합니다. 이전 `dynin-seminar-export-v1` 기록은 기존 실습 경로로 보존됩니다.
