# 현재 구현과 검수 상태

2026년 11월 23일 · 실습 v0.5.4 · GitHub Pages 배포 구성

전자 조립과 계측 판독을 강의용 예시로 실행할 수 있습니다. 준비된 관찰 예시를 사용하고, 실제 PDF 추출·기준 비교·작업자 답변·판정·보고서 생성은 브라우저에서 처리합니다. GPU, API 키, 실시간 모델 서버는 필요 없습니다.

최종 재검수와 [설명용 슬라이드 34장](../slides/README.ko.md)을 추가했습니다. 슬라이드 HTML·PDF·PowerPoint와 강사 진행 메모를 배포팩에 포함합니다. [최종 검수와 강의 준비](FINAL_CHECK.ko.md)에 새 검수 범위와 강의 PC 확인 항목을 정리했습니다.

v0.5.1에서 슬라이드의 제목·본문·도해 설명을 일반 강의 제목과 명사형 불릿으로 정리했습니다. v0.5.3는 [자료 다운로드 화면](../downloads.html), 수강생용 예제 ZIP, 공개 GitHub 저장소와 Pages 배포 구성을 추가합니다. 문서 다운로드가 끝나기 전에 정보 구축을 누르는 상황을 막도록 제품·PDF·CSV를 함께 준비한 뒤 화면에 반영합니다. 로딩 실패 시 이전 제품을 유지합니다. 판정 조건은 v0.5와 동일합니다.

v0.5.4는 강의 도입을 솔루션 소개 25분과 접속·자료 준비 25분으로 확장한 슬라이드 개편본입니다. 설명 슬라이드 34장과 강사 메모를 갱신했으며, 기존 실습 앱과 판정 조건은 변경하지 않았습니다.

## 계측 판독: 제품 선택부터 검수조서까지

[계측 실습 안내](MEASUREMENT_DEMO.ko.md)를 따라 가상의 다온정밀 플랜지 부시를 검사합니다.

| 단계 | 현재 동작 |
|---|---|
| 제품 선택 | 표준형 BSH-2630 / 정밀형 BSH-2630-P, 제품별 도면·시편 분리 |
| 정보 구축 | 작업지시서 PDF 실제 텍스트 추출 + CSV 검증 → 제품·도면·개정·위치·기준을 SQLite에 구성 |
| 측정 기록 | A 외경 26.30 mm, B 길이 40.02 mm, C 두께 5.?8 mm를 도면 위치에 연결 |
| 확인 질문 | C의 가려진 숫자를 질문하고 작업자가 값·단위를 명시적으로 제출 |
| 판정 | 표준형 + 5.78 mm 답변: 충족 3 / 미답변: 충족 2 + 확인 필요 1 |
| 조건 비교 | 정밀형의 길이 40.02 mm는 허용 범위 39.99–40.01 mm를 벗어남 |
| 기준 변경 | 입력 수치를 유지한 채 재판정, 원본 도면 기준과 실습에서 바꾼 기준을 모두 보존 |
| 답변 재확인 | 이전 답변을 남기고 새 확인 대기, 미해결 요청이 있으면 완료로 표시하지 않음 |
| 저장 | 도면·계측 장면·한국어 글꼴 내장 HTML 검수조서/보고서, CSV·JSON·SQLite |

제품·도면·계측 장면과 최초 판독은 자체 제작한 교육용 예시입니다. 실제 OCR 결과나 물리적 검사 인증은 아닙니다. `578 mm`를 제출하면 범위 밖으로 기록하며 자동으로 `5.78 mm`로 고치지 않습니다. 제품을 바꾸면 이전 제품의 측정값을 새 제품으로 옮기지 않습니다.

## 전자 조립: 기존 실습 유지

기본 화면은 [강의용 전자 조립 예시](TEACHING_DEMO.ko.md)입니다. SOP 2쪽과 기준 CSV를 불러오고, 공개 영상의 준비·회로·프로펠러·배터리·스위치·외관 6개 장면을 진행합니다. 배터리 방향 질문에 긍정 답변하면 충족 6개, 반대 방향이면 충족 5개와 불일치 1개, 미답변 또는 영상만 인정하는 기준이면 충족 5개와 확인 필요 1개입니다.

이전 5개 작성 이벤트 실습과 실제 모델 응답 경로는 강사용 참고에 보존했습니다. 실제 응답 파일은 이번 수정에서 변경하지 않았습니다.

## 실행 검수

- 코어 테스트 **76개 통과**: 기존 60개 + 계측 16개.
- 계측 두 제품의 브라우저 E2E **18개 검증 그룹 통과**: 실제 PDF/SQLite, 질문·재확인, 단위/대상 거부, 허용 범위 변경, 제품 간 기록 분리, 저장/가져오기, 데스크톱·모바일, 독립 HTML 검수조서.
- 최종 계측 브라우저 검수: 로컬 정적 GET 183건, 페이지/HTTP 오류 0건, 외부/API/모델 호출 0회.
- 기존 전자 조립 전체 흐름과 기존 5개 작성 이벤트 실습 25개 체크포인트 회귀 통과. 실제 모델 경로의 새 브라우저 재실행은 하지 않았으며, 원본 요청·응답의 바이트 보존과 기존 코어 회귀를 확인했습니다.

정확한 범위와 실행 증거는 [계측 경로 계약](measurement_demo_v1/CONFORMANCE.md)과 [검수 기록](measurement_demo_v1/E2E_RECEIPT.json)을 따릅니다. 이전 결과는 수정하지 않고 `validation/measurement_demo_v1`에 이번 검사와 v0.3 배포본을 별도로 보관했습니다.

## 강의 환경

- 계측 실습은 자체 제작 SVG로 표시하므로 영상 코덱이 필요 없습니다.
- 질문 듣기는 브라우저 TTS입니다. 강의 PC의 한국어 음성과 스피커를 확인하세요. 작업자 답변은 버튼·텍스트이며 ASR은 없습니다.
- 전자 실습의 H.264 영상은 이번 검수용 Chromium에서 재생되지 않았습니다. 장면 사진 대체 경로는 통과했으며 강의 PC의 영상 재생은 별도로 확인해야 합니다.
- 검수조서 PDF는 인쇄의 ‘PDF로 저장’을 사용합니다. 저장한 HTML 검수조서는 더블클릭으로 열립니다.
- 전체 실습 앱은 ZIP을 풀고 로컬 서버 또는 정적 웹 호스팅으로 실행합니다. [시작 안내](../START_HERE.ko.md)를 참고하세요.

GitHub 공개 배포는 사용자의 11월 22일 요청에 따라 진행합니다. GPU·모델 호출, 자동 감독 메시지 재개, HTech 비공개 자료 사용은 없습니다. 배포 경로와 확인 방법은 [배포 안내](DEPLOYMENT.ko.md)를 참고하세요.
