# 실습 2 (계측 판독): 측정 기록과 검수조서

가상의 다온정밀 플랜지 부시를 검사하는 강의용 예시입니다. 제품·도면·계측 장면은 같은 제품의 A 외경, B 길이, C 두께에 맞춰 작성했습니다. OCR이나 모델을 호출하지 않으며 입력값 검증·허용 범위 비교·보고서 생성은 브라우저에서 실행합니다.

## 진행 순서

1. 홈에서 **계측 판독 · 도면과 검수조서**를 선택합니다.
2. **표준형 플랜지 부시**를 선택하고 도면을 확인합니다. **검사 기준 불러오기 · 정보 구축**으로 SOP PDF와 기준 CSV를 읽습니다.
3. **검사 시작 준비**에서 검사자 이름과 LOT를 입력합니다. 미리 채워진 예시를 그대로 사용해도 됩니다. **측정 기록 시작**을 누릅니다.
4. A 외경 장면의 숫자를 보고 `26.30`, 단위 `mm`를 입력한 뒤 **A 측정값 기록**을 누릅니다. 도면 위치와 기록표가 함께 바뀝니다.
5. **B 측정 장면으로**를 누릅니다. 길이 `40.02`, 단위 `mm`를 입력해 기록합니다.
6. C 두께 장면에서 **가려진 표시 확인 · Agent 질문**을 누릅니다. 표시 `5.?8 mm`의 가려진 숫자는 자동으로 채우지 않습니다. **질문 확인** 후 직접 확인한 값으로 `5.78`, 단위 `mm`를 입력하고 **확인값 기록**을 누릅니다.
7. **검수조서 만들기**로 결과를 검토한 뒤 검수조서를 저장합니다. 도면·계측 장면·이름·LOT·최초 표시·입력값·질문과 답변이 함께 남습니다.

이름과 LOT는 검사 시작 전에 입력하며 이후 해당 검사에 고정됩니다. 다른 검사나 다른 제품은 새 기록으로 시작합니다. 같은 브라우저에서는 새로고침 후 이어갈 수 있고, **진행 내보내기 / 가져오기**로 다른 PC에 옮길 수 있습니다.

## 직접 입력 예시

| 항목 | 입력 예시 | 표준형 기준 | 결과 |
|---|---|---|---|
| A 외경 | 26.30 mm | 26.10–26.50 mm | 충족 |
| B 길이 | 40.02 mm | 39.90–40.10 mm | 충족 |
| C 두께 | 작업자 확인 5.78 mm | 5.70–5.90 mm | 충족 |
| C 두께 비교 | 578 mm | 5.70–5.90 mm | 불일치, 소수점을 자동 보정하지 않음 |

기록을 다시 입력하려면 결과 화면의 **A/B/C 확인값 다시 입력**을 사용합니다. 이전 값과 최초 표시는 지우지 않습니다. 숫자 형식이 잘못됐거나 단위가 다르면 기록하지 않고 수정 안내를 보여 줍니다.

## 선택 비교

기본 실습 후 시간이 남을 때만 한 가지를 비교합니다.

- **숫자 변경:** A에 `26.60`을 입력하면 표준형 외경 기준 초과. 다시 `26.30`을 입력하면 현재 판정은 충족, 이전 입력은 이력에 보존.
- **제품 변경:** 정밀형은 B 길이 기준이 `39.99–40.01 mm`. 같은 `40.02 mm`도 불일치. 제품을 바꾸면 도면·기준·검사 기록을 새로 시작.
- **기준 변경:** 결과 화면에서 A 상한을 `26.25`로 바꾸면 기록값 `26.30`은 유지되고 판정만 변경. 도면 원본 기준과 실습 변경 기준을 보고서에 함께 표기.

기본 흐름에 추가 설정이나 퀴즈는 없습니다. 강사는 각 입력 후 도면 위치, 판정, 기록표가 바뀌는 이유를 설명하면 됩니다.
