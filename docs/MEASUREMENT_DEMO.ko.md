# 계측 실습: 도면에 측정값을 기록하기

가상의 다온정밀에서 플랜지 부시 한 개를 검사합니다. 제품을 선택하고 도면을 불러온 뒤, 세 위치의 측정값을 기록하고 불확실한 숫자 하나를 작업자에게 확인합니다. 마지막에는 도면·측정표·답변이 담긴 검수조서를 저장합니다.

**제품·도면·계측 장면·초기 판독은 강의용으로 구성한 예시입니다.** GPU나 모델 없이 실행합니다. 문서 추출, 기준 비교, 작업자 답변 기록과 보고서 생성은 실제 앱 동작입니다.

## 기본 시연: 표준형 제품

1. 실습 목록에서 **계측 판독 · 도면과 검수조서**의 **이 실습 시작**을 누릅니다.
2. **BSH-2630 / 표준형 플랜지 부시**를 고릅니다. 제품번호, 도면번호 `DR-BSH-2630`, 개정 `A`, 검사 시편 `EDU-BSH-001`을 확인합니다.
3. 준비된 검사 작업지시서와 기준을 불러옵니다. **검사 기준 불러오기 · 정보 구축**을 실행하면 PDF 텍스트와 CSV에서 회사·공정·검사 기준을 읽어 SQLite를 만듭니다.
4. **검사 시작 준비**를 누릅니다. 도면에서 **A 외경 → B 전체 길이 → C 플랜지 두께**를 확인한 뒤 **측정 기록 시작**을 누릅니다.
5. **A 측정값 기록**, **B 측정값 기록**을 차례로 눌러 `26.30 mm`, `40.02 mm`를 기록합니다. 값이 도면의 해당 항목과 측정표에 연결됩니다.
6. **C 측정값 기록**을 누르면 한 자리가 가려진 `5.?8 mm`에 대한 질문이 생깁니다. **질문 확인**을 먼저 누르고 작업자 역할로 값 `5.78`, 단위 `mm`를 입력한 뒤 **확인값 기록**을 누릅니다. **예시값 5.78 mm 넣기**는 입력칸만 채우므로 **확인값 기록**을 별도로 눌러야 합니다.
7. **검수조서 만들기**로 세 항목의 결과를 검토합니다. 다시 **검수조서 만들기**를 누른 뒤 **검수조서 저장**으로 파일을 저장합니다. 원래 불확실했던 표시와 작업자가 확인한 값은 구분되어 남습니다.

| 위치 | 검사 항목 | 예시 장비 | 표준형 허용 범위 | 예시 입력 |
|---|---|---|---|---|
| A | 플랜지 외경 | 디지털 캘리퍼스 | 26.10–26.50 mm | 26.30 mm |
| B | 전체 길이 | 디지털 하이트 게이지 | 39.90–40.10 mm | 40.02 mm |
| C | 플랜지 두께 | 디지털 마이크로미터 | 5.70–5.90 mm | 최초 5.?8 mm → 작업자 답변 예 5.78 mm |

`5.78 mm`는 강사가 설명하기 위한 답변 예입니다. 실제 장비를 읽었거나 자동으로 인식했다는 기록을 만들지 않습니다. 수강생이 버튼 또는 입력으로 제출해야 답변이 기록됩니다.

## 비교 활동

- **확인하지 않기:** C 질문에 답하지 않고 검수조서를 만들면 충족 2개와 확인 필요 1개가 남습니다.
- **범위를 벗어난 값 답하기:** C에 `6.08 mm`를 입력하면 C는 불일치가 됩니다. 화면에 맞는 값으로 자동 수정하지 않습니다.
- **기준 바꾸기:** 결과 화면의 B **실습 상한 (mm)**을 `40.10`에서 `40.01`로 바꾸고 **새 기준 적용**을 누르세요. 측정값 `40.02 mm`는 그대로이고 판정이 바뀝니다. 기준을 되돌려 적용하면 다시 계산합니다.
- **제품 바꾸기:** 새 실습에서 **BSH-2630-P · 정밀형**을 선택합니다. 다른 제품·도면·시편으로 새 기록을 시작합니다. 같은 설명용 수치를 쓰더라도 정밀형 길이 허용 범위는 `39.99–40.01 mm`이므로 B가 불일치입니다.
- **단위 확인하기:** 질문에 `inch`처럼 다른 단위를 넣으면 거부됩니다. 같은 숫자라도 단위를 임의로 맞추지 않습니다.

제품 선택은 영상의 물체를 자동 분류한 결과가 아닙니다. 도면의 A/B/C 연결도 준비된 검사 위치에 기반합니다. 이 실습의 목적은 제품과 기준의 연결, 값과 단위, 추가 질문, 판정과 기록의 관계를 이해하는 것입니다.

이미 제출한 값을 바꾸려면 결과 화면의 **C 확인값 다시 입력**을 누릅니다. 질문 화면에서 **질문 확인**을 다시 누르고 새 값과 단위를 **확인값 기록**으로 제출하세요. 이전 값은 이력에 남으며 재확인 중에는 완료로 표시하지 않습니다.

## 산출물

검수조서에는 제품·도면 개정·시편, A/B/C 기준과 측정값, 최초 표시, 작업자 확인값, 질문과 답변, 검사 장면, 기준 변경 이력이 들어갑니다. 서명과 실제 검사일을 자동으로 만들어 넣지 않습니다. 보고서 HTML, 검사 CSV, 진행 JSON, SQLite 파일을 저장할 수 있습니다.

질문 듣기는 브라우저 음성 출력입니다. 작업자 답변은 버튼·텍스트이며 음성 인식은 포함하지 않습니다.

완료 형태를 먼저 보여주려면 아래 파일을 열면 됩니다. 도면·장면·글꼴이 들어 있어 인터넷 연결 없이 열립니다. 모두 강의용 예시에 작업자 역할 답변을 입력해 실제 앱에서 저장한 결과입니다.

- [표준형 완료 검수조서](measurement_demo_v1/examples/inspection-standard.html): 3개 항목 충족.
- [정밀형 비교 검수조서](measurement_demo_v1/examples/inspection-precision.html): 길이 1개 불일치.
- [표준형 결과 보고서](measurement_demo_v1/examples/report-standard.html).

## 교재 재생성

```sh
python scripts/prepare_measurement_demo.py
```

이 제작 명령에는 PyMuPDF와 fontTools가 필요합니다. 학생이 이미 만들어진 실습팩을 실행할 때는 필요 없습니다. 명령은 두 새 제품의 교재와 카탈로그만 갱신하고, 기존 전자 조립·실제 응답·기존 계측 사례 파일의 바이트가 유지되는지 검사합니다.
