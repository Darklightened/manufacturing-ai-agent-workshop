## 원인 해석과 강의에서의 사용

전송된 현재 이미지의 바이트·ID·시각은 정확합니다. 현재 프레임을 빼먹거나 이전 프레임 파일을 잘못 전달한 오류는 발견되지 않았습니다. 다만 입력에는 이전 모델 문장과 여러 역사 프레임이 함께 있고 e4/e5에서 이전 작업 설명이 이어집니다. **과거 상태에 과도하게 의존했거나 현재 장면에 충분히 주의를 주지 못했을 가능성**이 있지만, 입력 조건을 바꾼 대조 실행을 하지 않았으므로 원인으로 확정하지 않습니다.

또한 교육용 기준에 해석 여지가 있습니다. `E-BATTERY`는 두 개와 방향 확인을 요구하지만 승인된 홀더 극성 도면을 제공하지 않습니다. 106.996초 사진에서는 배터리 몸체의 `−`/`+` 표식이 보이지만, 표식을 읽는 것과 제조사 기준에 맞는 방향인지 판단하는 것은 별개입니다. `E-FINAL`은 프로펠러 외관 기록인데 모델이 스위치 동작 완료를 추가 선행조건으로 삼았습니다. 이러한 의미 차이는 증거 정책 변경으로 몰래 수정하면 안 됩니다.

강의에서는 다음을 분명히 구분합니다.

1. **실제 모델이 읽은 내용:** 저장된 원본 응답으로 재생합니다. 이상한 부분도 그대로 남깁니다.
2. **현재 기준에 따른 제어기 판정:** 같은 관찰을 재사용해 증거 인정 정책을 다시 적용합니다. 모델 지각이 새로 개선되었다고 표시하지 않습니다.
3. **작업자 확인:** 정확한 대상과 질문에 대한 답변이며 영상 증거와 별도 출처입니다. 허용 정책을 바꾸면 반영 여부가 달라지고, 기존 원시 응답과 이전 판정은 유지합니다.
4. **끝까지 남은 항목:** 마지막 `not_due`나 보류를 자동 합격으로 지우지 않습니다. 완료 보고서는 미확인·미검사 항목을 포함한 상태로도 출력할 수 있어야 합니다.
