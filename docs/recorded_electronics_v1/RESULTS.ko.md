# 전자 조립: 실제 모델 응답으로 진행하는 실습

2026년 11월 22일 · 실제 응답 수집 완료 · 모델 서버 종료 후 브라우저 E2E 검수 완료

전자 조립 기본 실습을 **실제 Qwen FP8 응답의 저장 재생**으로 연결했습니다. 강의 중에는 GPU, API 키, 모델 서버가 필요 없습니다. 실제 PDF 추출·SQLite 구축, 응답 재생, 작업자 확인, 증거 정책 변경, 재판정, 보고서 내보내기가 하나의 경로로 이어집니다.

기술 실행 검수는 통과했지만 모델의 작업 분류가 모두 맞지는 않습니다. 오류도 원본 그대로 보존합니다. [장면별 검수](SOURCE_REVIEW.ko.md)와 [기계가 읽는 검수 요약](E2E_RECEIPT.json)을 함께 확인하세요.

## 수업에서 실행하기

전체 묶음에서 `python scripts/serve.py`를 실행하고, 실행한 PC에서 `http://127.0.0.1:8921/`을 엽니다.

1. **전자 조립**을 선택합니다. 실제 응답팩의 요청·응답·이미지·원본 문서 해시를 확인한 뒤 재생 모드를 활성화합니다. 누락·불일치 파일이 있으면 실제 재생을 거부하고 원인을 표시합니다.
2. 준비된 SOP PDF와 기준 CSV로 **정보 구축**을 누릅니다. PDF.js로 실제 텍스트를 추출하고 SQLite에 저장합니다. 초기 SOP의 작성 이벤트 안내는 이전 교재 설명이며 현재 관찰 출처는 실행 모드를 따릅니다.
3. 작업 설정에서 **실제 응답 재생**을 선택하고 **작업 시작**을 누릅니다. 기본으로 선택되어 있습니다.
4. **다음 관찰**로 6개 시점을 진행합니다. 예정 작업 목록과 모델이 관찰한 작업·단계를 구분해 봅니다. 모델 입력·출력 펼치기에서 실제 프롬프트, 개별 입력 사진, 원시 응답을 확인합니다.
5. 연결 검사 `E-CONNECTION`의 질문을 화면으로 전달하고 대상 `circuit-board`, 확인 결과 **충족**, 구체적인 확인 내용을 제출합니다. 이는 수강생 역할 실습이며 실제 현장 검사자가 확인했다는 뜻은 아닙니다.
6. 기본 정책은 **시각 증거만 인정**이므로 모델의 불명확한 관찰은 계속 **확인 필요**로 남습니다.
7. 검사 결과의 **기준을 바꾸어 비교**에서 같은 항목을 **작업자 직접 확인도 인정**으로 바꾸고 **기준 적용 · 재판정**을 누릅니다. 이 항목만 **작업자 확인에 따른 충족**으로 바뀝니다.
8. 다시 **시각 증거만 인정**으로 바꾸면 **확인 필요**로 돌아갑니다. 원래 모델 관찰과 제출한 답변은 삭제되지 않습니다.
9. 별도 확인에서 작업자가 **불일치**라고 답하고 작업자 확인 허용 정책을 적용하면 해당 항목은 **불일치**가 됩니다. 다른 대상의 답변은 거부합니다.
10. 각 상태에서 **보고서 만들기 → 사진 포함 HTML 저장 / 검수조서 저장**을 실행해 비교합니다. **판정 변경 이력**, 실행 JSON, CSV와 SQLite도 저장할 수 있습니다.

전자 조립에는 계측 수치가 없으므로 가상의 허용 범위를 추가하지 않았습니다. 이번 기준 변경은 **어떤 증거를 인정할지**를 비교하는 것입니다. 검사 항목의 의미·대상·작업 순서를 바꾸는 것은 기존 응답 재생 범위를 벗어나므로 새 수집이 필요합니다.

## 실제 모델 입력과 출력

| 항목 | 실제 설정 |
|---|---|
| 영상 | 공개 EgoOops `S1790005`, 약 121초 |
| 모델 | 기존 Qwen3.8-27B-FP8 스냅샷, 리비전 `017b9c7af6b5689d5dd426a76e0bc077eb5ca20a` |
| 조건 | thinking off, temperature 0, 최대 출력 2,560토큰 |
| 문서 문맥 | 실제 PDF에서 추출한 원본 8단계·교육 작업군 5개·검사 조건 5개·대상 |
| 관찰 시점 | 20.361 / 76.731 / 89.659 / 99.726 / 113.870 / 120.021초 |
| 요청별 이미지 | 3 / 5 / 6 / 7 / 9 / 10장. 해당 시점까지의 실제 키프레임만 전달 |
| 과거 문맥 | 앞선 실제 모델 출력과 해당 시점까지의 과거 이미지 |
| 제외 | 기존 작성 이벤트의 정답·해설, 현재 작업 정답, 미래 이미지, 가상 작업자 답변 |
| 저장 출력 | 관찰 작업·단계, 조건별 관찰·적용 시점·대상 확인·인용 프레임·한국어 이유·질문 후보 |

6회 요청 모두 정상 종료했고, 30개 관찰 후보를 저장했습니다. HTTP 서비스 시간은 총 **49.79초**, 평균 **8.30초/요청**입니다. 서버 기동 시간은 제외합니다. 응답 생성은 784~816토큰이며 reasoning 토큰은 0입니다. 재생 중에는 이 시간이 다시 들지 않습니다.

요청에는 1280×720 JPEG를 그대로 저장했지만 실제 모델의 비전 처리에는 서버 리사이즈가 적용됩니다. 원본 픽셀 수와 모델의 내부 비전 토큰 수를 동일하게 취급하지 않습니다. [서빙 설정](../../recordings/electronics_v1/execution_environment.json), [실제 응답팩](../../recordings/electronics_v1/pack.json), [수집 요약](../../recordings/electronics_v1/capture.summary.json)을 보존했습니다.

## 최종 시점의 기본 결과

| 검사 항목 | 저장된 모델 관찰 | 기본 정책 판정 |
|---|---|---|
| S2–L1 병렬 연결 | 정확한 연결 구조 불명확 | 확인 필요 |
| 프로펠러 장착 외관 | 장착 외관이 보임 | 충족 |
| 배터리 수량·방향 | 두 개 삽입은 보이지만 방향 확인 불충분 | 확인 필요 |
| S1·S2 조작 순서 | 실제 조작 순서를 확인하기 어려움 | 확인 필요 |
| 최종 외관 기록 | 모델이 아직 최종 단계가 아니라고 판단 | 미도래 — 장면 검수에서 적용 시점 오류 지적 |

기본 합계는 **충족 1 / 확인 필요 3 / 미도래 1**이며 전체 합격으로 처리하지 않습니다. 마지막 프레임에 도달한 것과 모든 검사가 완료된 것을 구분합니다.

같은 원본 응답으로 연결 검사 하나의 답변·정책만 바꾼 실제 브라우저 검수 결과입니다.

| 조건 | 연결 검사 | 전체 충족 / 불일치 / 확인 필요 / 미도래 |
|---|---|---|
| 영상 증거만 + 작업자 긍정 답변 | 확인 필요 | 1 / 0 / 3 / 1 |
| 작업자 직접 확인 허용 | 작업자 확인에 따른 충족 | 2 / 0 / 2 / 1 |
| 다시 영상 증거만 | 확인 필요 | 1 / 0 / 3 / 1 |
| 작업자 불일치 답변 + 확인 허용 | 작업자 확인에 따른 불일치 | 1 / 1 / 2 / 1 |

원래 30개 모델 관찰은 모두 동일합니다. 판정·현재 정책·작업자 진술·이전 이력·보고서만 새 상태를 반영합니다. 명확한 모델 관찰과 작업자 진술이 반대라면 자동 덮어쓰기 대신 충돌 보류를 사용합니다.

## 무엇을 검수했는가

- 기존 작성 이벤트와 새로운 재생 경로의 코어 테스트 43개 통과.
- 실제 요청·응답 및 원본 문서·이미지 파일 해시 56회, 실제 요청에 포함한 이미지 바이트 40건 대조 통과.
- GPU 서버를 종료한 뒤 Chromium에서 PDF 추출, SQLite 구축, 6개 실제 응답 재생, 질문 전달, 잘못된 대상 거부, 답변·정책 재판정, 보고서 저장을 통과.
- 새로고침·새 브라우저 세션에 JSON 가져오기, 변조된 실행 기록 거부, 원시 응답 누락 시 실제 모드 거부 확인.
- 보고서와 검수조서에 사진·한글 글꼴을 내장하고, SQLite에서 변경된 정책과 판정을 직접 조회.
- 실제 브라우저 검수 중 정적 GET 455회, 외부 요청 0회, POST 0회, 모델 호출 0회, 페이지 오류 0건. 모바일 390px 가로 넘침 없음.

한 번의 브라우저 검수에서 작업자 확인 선택지의 HTML 오류를 발견해 수정했습니다. 실패 기록은 따로 보존했으며 모델 응답을 다시 생성하지 않았습니다. 초기 GPU 승인 설정 충돌도 모델 호출 전에 종료·복구했고 그 기록을 보존했습니다. 최종 수집은 6회만 실행했습니다.

## 해석의 한계

연속 영상 전체 인식이 아니라 희소 키프레임 기반입니다. 모델은 후반에 배터리 삽입을 프로펠러 장착으로, 스위치 조작을 배터리 삽입으로 늦게 분류했습니다. 최종 외관 항목에는 SOP에 명시되지 않은 스위치 완료 선행조건을 만들어 적용했습니다. 입력 이미지가 잘못 전달된 것은 아니며, 이전 문맥의 영향인지 밝히는 비교 실험은 하지 않았습니다.

따라서 이 버전은 **실제 모델이 틀릴 수도 있다는 전제 아래, 근거·확인·정책·보고서를 다루는 실습**으로 사용할 수 있습니다. 모든 공정이 자동 합격하는 시연이나 현장 정확도 검증으로 소개하지 않습니다. 작업자 답변 역시 실제 제조 검사 결과가 아닌 실습용 입력입니다.

음성 출력 버튼은 브라우저 TTS를 사용하며, 각 강의 PC의 한국어 음성 품질은 별도 리허설이 필요합니다. ASR·실시간 스마트글래스·OCR·새로운 영상 추론은 이 재생판에 연결하지 않았습니다.
