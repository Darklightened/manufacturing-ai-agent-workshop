# 실습 3 (기계 조립): 영상 진행과 단계별 확인

공개 IndustReal 조립 영상에 수업용 검사 항목을 연결했습니다. 차체·브래킷·바퀴 축·최종 외관을 순서대로 확인합니다. 새 모델을 실행하지 않으며 **강의용 예시**로 표시합니다.

## 진행 순서

1. 홈의 **기계 조립 · 영상으로 단계 확인**을 선택합니다.
2. SOP와 검사 기준을 확인하고 **정보 구축**을 누릅니다. **작업 설정으로** 이동해 공정과 네 작업군을 확인하고 **작업 시작하기**를 누릅니다.
3. **영상 재생**을 누릅니다. 기본 2배속이며 1·2·4배속을 선택할 수 있습니다. 진행 막대는 실제 재생된 원본 시각을 따릅니다.
4. 단계가 끝나면 해당 항목의 확인 표시와 Agent 통과 신호가 나옵니다. **다음 작업 시작**을 눌러 이어갑니다.
5. 단계 통과 후 **다음 작업은 어떻게 하나요?**를 누르면 작업자가 묻고 Agent가 다음 공정·방법·주의점을 안내하는 장면이 열립니다. 선택 기능이며 누르지 않아도 진행됩니다. 안내 내용은 검수 판정과 분리해 보고서에 남습니다.
6. 브래킷 단계에서는 안쪽 연결 핀이 손에 가려져 있습니다. **질문 확인** 후 직접 확인했다고 가정한 답변을 선택합니다. 잘못 끼워졌거나 확인하지 못했다고 답하면 다음 작업이 보류됩니다.
7. 마지막 외관 확인까지 마친 뒤 **검수 완료 · 결과 보기**와 **보고서 만들기**를 누릅니다. 사진 포함 HTML, 검수조서, 검사 CSV 등을 저장합니다.

## 영상과 검사 기준

| 원본 영상 구간 | 작업군 | 확인할 내용 |
|---|---|---|
| 0:00–1:10 | 차체 연결 | 긴 차체 부재와 연결 부재의 조립 외관 |
| 1:10–1:30 | 브래킷 배치 | 전방 브래킷 위치, 가려진 안쪽 연결 핀의 작업자 확인 |
| 1:30–2:58 | 바퀴 축 조립 | 앞뒤 두 바퀴 축이 각각 조립된 외관 |
| 2:58–3:04 | 최종 외관 | 네 바퀴와 브래킷이 포함된 전체 조립 모습 |

눈에 보이는 조립 외관만 예시 관찰에 반영합니다. 토크·체결력·치수·주행 성능을 영상에서 측정한 것으로 표시하지 않습니다. 가려진 핀의 원래 관찰은 미확인으로 남기고 작업자 답변을 별도 근거로 기록합니다.

## 강의 진행 포인트

영상은 계속 재생하고, 설명이 필요할 때만 일시정지합니다. 수강생이 입력해야 하는 답변은 가려진 연결 핀 한 곳입니다. 단계마다 추가 퀴즈나 설정을 요구하지 않습니다.

시간이 남으면 핀을 **아직 확인하지 못함 → 직접 확인 완료**로 바꿔 통과 신호의 변화를 비교합니다. 결과 화면의 증거 기준을 **시각 증거만 인정**으로 바꾸면 작업자 답변만으로 통과하지 않는 것도 확인할 수 있습니다. 이전 답변과 관찰은 보존합니다.

보고서나 검수조서를 저장하면 마지막 **문서 보관함**에도 사본이 쌓입니다. 다른 실습의 저장 문서와 완성 예제를 함께 열고 다시 다운로드할 수 있습니다. 같은 이름으로 여러 번 저장해도 이전 파일을 남깁니다.
