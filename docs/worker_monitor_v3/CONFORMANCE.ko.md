# 작업자·모니터링 경로 검수

범위: 교육용 웹앱의 화면·문서 구성. 모델 호출이나 GPU 실험 없음. 기존 시나리오·코어·회사 자료 구축·슬라이드 보존.

| 유지 항목 | 이번 연결 |
|---|---|
| 영상 시간·단계 통과 | 전자/기계 조립의 원래 재생 시간과 검사 상태 사용, 화면 전환은 판정 이벤트를 만들지 않음 |
| 불명확한 항목 | 질문 전달 후 작업자 확인, 부정·미확인 답변의 보류와 이전 답변 보존 |
| 계측 수치 | 소수점·단위 검증, 입력578을5.78로 임의 보정하지 않음, 규격 변경 시 원시 값 보존 |
| 도면 | 공칭 치수·허용 범위와 실제 입력값을 분리, A/B/C 치수 위치에 기입 |
| 보고서 | 검사표·사진·수치·질문 이력 및 미해결 항목 보존, 서명/승인 생성 없음 |
| 저장 | 같은 상태로 복원/가져오기, 다운로드한 실제 파일을 문서 보관함에 저장 |
| 출처 | authored provenance 유지, 원본 영상·사진·기존 결과 보존, 제작 안내는 사용 화면에서 분리 |

실제 브라우저 검수: 전자 조립11개 그룹, 계측6개 그룹, 기계 조립4개 그룹 통과. 영상은 실제 디코딩 재생으로 진행했으며 검사 통과를 위해 시간을 주입하지 않았습니다. 계측은 실제 PDF 추출·SQLite 구축, 양 제품 수치·단위 오류, 기존 기록 복원, HTML/CSV/SQLite 내보내기까지 확인했습니다.

초기 계측 검수 스크립트는 기존 HTML 요소용 `inner_text()`를 새 SVG 요소에 사용해 멈췄습니다. 도면의 `text_content()`를 읽도록 검증 코드를 수정한 뒤 전체 경로가 통과했습니다. 초기 PDF 표지 인쇄 넘침은 인쇄용 여백을 조정한 후 다시 확인했습니다. 중간 로컬 서버 종료로 인한 연결 실패는 별도 기록하고 서버를 복구한 뒤 후속 검수를 진행했습니다.

측정 장면의 카메라 시점 영상은 기존 이미지에서 만든10초 프리뷰이며 실제 글래스 촬영이나 독립적인 측정 증거가 아닙니다. 영상 출처는 manifest에 보존했습니다. 브라우저의 실제 음성 출력 품질과 Native Word 실행은 검증하지 않았습니다. 파일 구조·화면과 인쇄 결과 검수는 물리적 품질 검증을 의미하지 않습니다.

최종 검수는 Node156개(기존149개+도면·보고서7개), 저장된 실제 응답의 바이트 검증 및 기존 재생 audit를 포함합니다. 기계 조립 보고서4개 그룹에서 보관함 미리보기·동일 바이트 다운로드·오프라인 열기까지 확인했습니다. A4 인쇄는 전자 조립6쪽, 계측4쪽, 기계 조립3쪽입니다. 슬라이드와 코어·회사 구축·시나리오286개 보존 파일의 해시는 동일합니다.

## 항목별 체크 표시 v0.8.1

공통 표시 모듈은 각 실습의 현재 판정에서 검사 목록을 그립니다. `met`만 ✓로 표시하며, 첫 미완료 항목으로 강조를 이동합니다. 영상 검사 시점·단계 통과 조건을 바꾸거나 표시 시간이 지났다는 이유로 통과시키지 않습니다. 불일치와 확인 대기는 각각 !와 ?로 유지하고, 답변 재확인 시 기존 수치가 남아 있어도 체크를 해제합니다.

기존156개 Node 검사를 통과했습니다. 전자 조립은 자연 재생으로 첫 항목→둘째→셋째 전환, 배터리 부정·미확인·긍정 답변,18항목과6단계, 저장/가져오기·기준 재검토를 확인했습니다. 기계 조립은 브래킷 위치 통과 후 연결 핀 확인 대기와 답변별 체크를 확인했습니다. 계측은 A/B 통과, C 미확인·578불일치·재확인5.78, 원시 값과 이전 답변 보존을 확인했습니다. 슬라이드·시나리오·코어·자료 구축·보고서 관련306개 보존 파일은 동일합니다.
