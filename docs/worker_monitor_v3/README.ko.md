# 작업자 화면과 모니터링 화면

회사 자료 구축과 작업 설정은 기존과 동일합니다. 작업을 시작하면 주변 메뉴가 사라지고 작업 영상이 크게 표시됩니다.

| 화면 | 확인하는 내용 | 다음 조작 |
|---|---|---|
| 작업자 | 현재 작업 영상, 우측 상단 통과 알림·확인 요청 | 영상 재생, 필요한 답변 입력, 검사 기록 확인 |
| 모니터링 | 단계별 검사표, 작업 기록, 도면에 기록된 수치 | 다음 작업 시작 |
| 검사 결과 | 미확인·불일치 항목, 작업자 답변, 적용 기준 | 결과 검토 후 보고서 저장 |
| 문서 보관함 | 생성한 보고서와 완성 예제 | 미리보기·다운로드 |

실습 1과 3은 영상 재생에 따라 단계가 진행됩니다. 단계가 끝나고 조건이 충족되어야 다음 작업으로 이동합니다. 작업자 화면에서 **검사 기록 확인**을 누르면 모니터링 화면으로 전환합니다. 여기에서 **다음 작업 시작**을 누르면 다음 단계의 작업자 화면으로 돌아옵니다. 상단 전환 버튼으로 언제든 두 화면을 비교할 수 있습니다.

실습 2는 A 외경과 B 길이를 입력하고, C 두께의 불명확한 표시를 확인 질문으로 해결합니다. 측정값을 기록한 후 **모니터링에서 기록 확인**을 누릅니다. 도면에 해당 값·단위·상태가 기입됩니다. 다음 측정을 시작하면 다시 작업자 영상으로 이동합니다. 규격 이탈 값은 그대로 기록되며 마지막 검사 결과에서 검토합니다.

검수조서는 회사·제품·작업 지시·검사 기준, 검사 항목별 결과, 확인 이력, 증거 사진을 표 중심으로 구성합니다. 계측 보고서는 치수 기입 도면을 포함합니다. 확인·승인 서명은 비워 둡니다. HTML은 이미지와 글꼴을 내장해 저장하며, 전자 조립은 편집 가능한 DOCX도 제공합니다. 인쇄에서 PDF로 저장할 수 있습니다.

화면에 반복되던 제작 방식 설명은 자료 안내로 옮겼습니다. 교육용 시나리오와 영상 출처는 기존 메타데이터·라이선스 문서에 보존합니다. 두 화면은 같은 브라우저 기록을 보여주며 별도 작업자 단말과 관리 서버가 연결된 시스템은 아닙니다. 실제 OCR·영상 인식·마이크 인식은 실행하지 않습니다.

슬라이드는 이번 변경에 포함하지 않았습니다.
