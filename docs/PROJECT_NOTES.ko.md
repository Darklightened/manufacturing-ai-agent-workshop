# 기존 프로젝트에서 이어받는 원칙

이 실습은 기존 제조 하네스의 설계와 교훈을 참고한 독립 교육 경로입니다. 회사의 비공개 자료·실험 결과·운영 서버를 공개 앱으로 복사하지 않습니다. 기존 계획 문서에 있던 내부 연구 링크는 이 설명으로 연결했습니다.

- 모델의 작업 가설, 관찰 가능한 사실, 검사 결과와 작업 완료는 구분합니다.
- 예상 순서를 안다고 앞 단계의 성공을 채우지 않습니다.
- 가린 부위는 보류하며 명확한 추가 증거를 요청합니다.
- 측정값의 원문·단위·대상·장비를 유지하고 목표 범위에 맞춰 소수점을 옮기지 않습니다.
- 질문의 전달·답변·대상 연결·해결을 구분합니다.
- 분해·교체 이후 이전 증거의 유효성을 다시 평가합니다.
- 원시 응답과 실패는 보존하며 작성한 이벤트를 실제 모델 응답으로 표시하지 않습니다.
- 학생 입력·규정 버전·실행 기록이 같은 보고서에 연결되어야 합니다.

전자 조립의 실제 응답 재생 경로는 [별도 인계 기록](recorded_electronics_v1/EXPERIMENT_CHECKLIST.md)에 따라 구현했습니다. 다른 실습은 작성 이벤트 경로를 유지합니다. 이전 연구 경로의 성능 수치를 이 앱의 성능으로 가져오지 않습니다.
