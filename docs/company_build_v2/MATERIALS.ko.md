# 회사별 입력 자료 묶음

2026-11-23 · 회사 자료 구축 실습용 · 로컬 준비본

수강생은 `assets/company-materials/company-practice-materials.zip`을 풀고, 전자 조립의 폴더 선택에서 `다온에듀테크`를 선택합니다. 현재 수강생 실습 3개를 회사 2개로 묶었습니다. 과거 강사용 실험·실제 모델 응답·비공개 회사 데이터는 포함하지 않습니다.

| 회사 | 구성 | 파일 수 |
|---|---|---:|
| 다온에듀테크 | 회사 개요, SOP, 검사 기준, BOM, 조립 구성도 PDF·SVG, 공정 순서 | 7 |
| 다온정밀 / 표준형_BSH-2630 | 제품 개요, SOP, 검사 기준, 도면 PDF·SVG, 제품 외관, 계측 장면 A·B·C | 9 |
| 다온정밀 / 정밀형_BSH-2630-P | 표준형과 동일한 파일 종류, 별도 제품·도면·검사 범위 | 9 |

총 입력 파일 25개, ZIP 안내와 글꼴 고지 포함 27개입니다. ZIP은 690,259바이트이며 영상·프로그램·완성 보고서·슬라이드는 포함하지 않습니다. 기존 큰 배포 ZIP과 공개 페이지는 이번 자료 생성 작업에서 갱신하지 않았습니다.

## 원문과 검토용 초안 구분

회사 문서는 올바른 원본입니다. 전자 조립의 `E-BATTERY`는 `battery`(배터리 삽입)에 연결되며 배터리 수량은 2개입니다. `E-SWITCH`는 `switch`에 연결되고 S1 확인 후 S2 확인 순서입니다. 앱에서 보여줄 의도적인 초안 오류는 원본을 수정하지 않고 별도로 만듭니다.

조립 구성도는 부품과 작업 순서의 교육용 안내도입니다. 실제 위치·배선 치수나 제조용 전기 회로도를 나타내지 않습니다. SVG는 한글 글꼴을 경로로 변환하여 독립 미리보기에서 글꼴 누락을 방지합니다. PDF는 Noto Sans KR을 포함하며 고지를 함께 제공합니다.

## 생성과 검수

`python scripts/prepare_company_materials.py`

- 기존 세 실습의 SOP·검사 기준 6개 복사본 원본 바이트 일치
- 매니페스트 25개 경로·SHA256 및 ZIP 내부 내용 일치
- ZIP 무결성·상대 경로·명시적 파일 목록 확인
- 새 조립 구성도 PDF를 실제 렌더링해 한글·상자·작업 순서 확인
- 입력 원본 E-BATTERY → battery 및 BOM 배터리 수량 2 확인
- 모델 호출·GPU 사용·공개 업로드 없음

해시와 파일별 설명은 `assets/company-materials/manifest.json`을 따릅니다. 이 자료 준비 검수는 폴더 업로드 UI, DB 수정 및 전체 실습 실행 검수와 별도입니다.
