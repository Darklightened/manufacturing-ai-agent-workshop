# 실습 1: 회사 자료 구축 개편안

회사 폴더 업로드부터 기준 검토·온톨로지 확인까지의 안내입니다. [현재 강의 자료](../../slides/README.ko.md)의 예제 해설과 실제 화면 순서에 맞춰 진행합니다.

## 수강생의 진행 순서

1. 전자 조립 실습을 선택하고 **전체 회사 자료 ZIP 받기**를 누릅니다.
2. ZIP을 풀고 **폴더 전체 업로드**에서 **다온에듀테크** 폴더를 선택합니다. 폴더 선택이 어려운 환경에서는 **파일로 선택**으로 여러 파일을 고릅니다.
3. 파일별 체크박스로 사용할 자료를 정합니다. 최소 한 개를 선택합니다. 파일 이름을 누르면 PDF, CSV, 도면, 텍스트가 오른쪽에 표시됩니다. PDF는 쪽을 넘길 수 있습니다.
4. **선택 자료로 정보 구축**을 누릅니다. 파일 분류 → PDF 텍스트 추출 → 도면·부품표 분석 → 공정·검사 기준 연결 → SQL DB 구성 → 검토 항목 확인 순서로 화면과 출력 로그가 바뀝니다. 각 단계의 진행률은 0–100%입니다.
5. **DB 검토와 수정**에서 작업지시서와 SQLite 행을 비교합니다. 배터리 방향 기준 `E-BATTERY`가 `회로 연결(circuit)` 작업에 잘못 연결되어 있습니다.
6. 연결할 작업을 **배터리 삽입(battery)**으로 바꾸고 **수정 내용 저장**을 누릅니다. 다른 작업으로 수정하면 이력은 남지만 완료로 넘어가지 않습니다. 수정 근거는 선택 입력입니다.
7. **검토 완료 · 온톨로지 보기**를 누릅니다. 회사 → 공정 → 여섯 작업 → 검사 기준·근거 문서의 연결을 확인합니다. 작업을 클릭하면 해당 기준이 바뀝니다.
8. 여기까지가 자료 구축입니다. 이후 **자료 구축 완료 · 작업 설정으로**를 눌러 기존 조립 실습을 이어갑니다.

## 회사별 입력 자료

[회사 자료 ZIP](../../assets/company-materials/company-practice-materials.zip)은 약 0.69 MB입니다. 다온에듀테크 7개, 다온정밀 표준형 9개·정밀형 9개 입력 자료를 회사 폴더로 묶었습니다. 원본 코드·영상·슬라이드는 이 입력 자료 ZIP의 대상이 아닙니다. 자세한 파일 목록은 [자료 구성](MATERIALS.ko.md)을 참고합니다.

## 실제 동작과 교육용 예시

| 구분 | 현재 동작 |
|---|---|
| 폴더·선택·미리보기 | 실제 로컬 파일 읽기. 서버에 업로드하지 않음 |
| 구축에 쓰는 자료 | 선택 조합과 무관하게 동일한 다온에듀테크 공통 예제 사용 |
| PDF·CSV | 공통 예제 PDF를 PDF.js로 실제 추출하고 CSV 기준을 검증 |
| 도면·부품 분석 | 준비된 교육용 해석 예시. 임의 도면 분석이나 모델 추론은 수행하지 않음 |
| 진행률 | 기술 흐름 설명을 위한 단계별 재생. 실제 처리 시간이나 모델 상태를 나타내지 않음 |
| DB | sql.js의 실제 SQLite. 초안·원본·선택 자료·검토 이력을 별도 테이블로 저장 |
| 잘못된 연결 | 검토 과제를 위해 초안에만 삽입. 원본 SOP·CSV는 변경하지 않음 |
| 완료 이후 | 원본과 일치하는 검토 결과를 기존 작업·질문·보고서 제어기로 전달 |

화면에도 이 구분을 표시합니다. 새 모델 호출, OCR 호출, GPU 실행은 없습니다.

## 복원과 다시 시작

선택한 파일과 진행은 기존 브라우저 IndexedDB에 저장합니다. 선택 화면에서 새로고침해도 파일 미리보기를 이어갑니다. DB 검토 중의 잘못된 수정 시도도 유지합니다. 구축 도중 새로고침하면 완료로 간주하지 않고 자료 선택으로 돌아가 다시 구축하도록 합니다.

작업 시작 후 진행 JSON을 내보내면 자료 선택 메타데이터와 검토 이력도 함께 보존합니다. 로컬 원본 파일의 내용은 JSON에 넣지 않습니다. 다른 브라우저로 가져와도 온톨로지와 수정 기록을 볼 수 있습니다. 예전 진행 JSON에는 구축 이력이 없으므로 확정된 기준의 읽기 전용 요약을 표시합니다.

온톨로지에서 **검토 기록 다시 보기 → 선택 자료 다시 보기**를 누르면 앞선 검토를 보존하고 새 구축을 시작합니다. 새 자료 선택 후에는 다시 검토하기 전까지 작업 시작이 막힙니다. 이미 조립 작업을 시작한 세션의 회사 기준은 고정됩니다.

## 강사용 진행 제안

파일 선택·미리보기 5분, 구축 과정 해설 5분, DB 오류 수정 5분, 온톨로지와 작업 연결 확인 5분 정도의 첫 활동입니다. 실제 수강생 속도에 맞추어 조정합니다. 다운받기 어려운 환경에는 **다운로드 없이 화면을 확인하려면 → 준비된 회사 자료로 시작**이라는 보조 경로도 있습니다.
