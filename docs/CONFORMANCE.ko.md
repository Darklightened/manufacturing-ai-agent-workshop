# 교육용 제어 경로의 인계 검수

2026-11-21 · 경로 `11_21_seminar` · CPU/브라우저 교육용 구현 · 새 모델 요청 없음

이 기록은 교육용 작성 이벤트와 결정적 제어기 경로의 범위를 정의합니다. 기존 하네스 전체를 이식하거나 실제 제조 품질 정확도를 검증한 기록이 아닙니다. GPU 중단과 기존 연구 결과를 그대로 유지합니다.

| 교훈 | 이 경로의 구현 계약 | 검증 위치와 한계 |
|---|---|---|
| 출처·시각 | `scenarios/*.json`의 origin, checkpoint 시각, 원본 이미지 | 원본 주석과 작성 이벤트 구분. 실제 모델 wire payload 없음 |
| SOP/BOM | 교육용 PDF와 criteria CSV에서 명시적 정보 구축 | 회사 규정 인증이나 임의 PDF 의미 이해 아님 |
| 작업/완료 | 제어기의 진행 위치와 검사 상태 분리 | `packages/core/core.mjs`, `tests/core.test.mjs` |
| 대상·과거 증거 | checkpoint target과 criterion target 연결 | 영상 간 동일 개체 연결을 주장하지 않음 |
| 수치 검증 | 값·단위·구간·답변 출처 분리 | 동일 제품 다지점 검사 미구현, 독립 판독 사례 |
| 원시 출력 | authored_fixture 표시 | 실제 모델 응답을 저장했다는 주장 없음 |
| 질문 | 전달 이후 답변, 질문/대상 연결 검사 | 음성 인식은 실제로 연결되기 전에는 주장하지 않음 |
| 한국어 | 질문·화면·문서 | 기계 ID는 안정적으로 유지 |
| 실패·재개 | 원장·세션과 검증된 저장/가져오기 | 5개 팩 새로고침·새 컨텍스트 JSON 가져오기 검수 |
| 보고서 | 같은 기록에서 검수조서/보고서 | 서명·실측·검사 승인 생성 금지 |
| 공개 배포 | `scripts/build.py`의 허용 목록과 경로 검사 | 배포를 실행하지 않음 |

적용한 의도적 축소는 명확합니다. 인식은 작성 이벤트이며 실시간 모델·OCR·ASR은 실행하지 않습니다. 미지원 모델 모드를 실제 실행처럼 표시하지 않습니다. 문서와 규칙 처리의 통과가 인식 품질을 입증하지 않습니다.

검증 명령은 `node --test tests/core.test.mjs`, `python scripts/build.py`입니다. 실제 통과 결과는 해당 작업의 실행 기록과 별도 통합 검수 산출물을 따릅니다. 이 파일에 테스트 횟수나 브라우저 통과 여부를 미리 기입하지 않았습니다.
