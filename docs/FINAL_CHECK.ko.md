# 최종 검수와 강의 준비

2026년 11월 22일 · v0.5

전자 조립과 계측 판독의 실제 브라우저 흐름을 다시 검수했습니다. **코어 76/76개, 계측 18개·전자 14개 검증 그룹이 통과**했고 앱 결함은 발견하지 않았습니다. PDF 추출·SQLite, 질문·답변·재확인, 제품 분리, 기준 변경, HTML·CSV·JSON·DB 저장과 복원을 포함합니다. 두 E2E의 로컬 GET는 319건, 페이지·HTTP 오류와 외부/API/모델 호출은 모두 0건입니다.

| 예시 조건 | 검수 결과 |
|---|---|
| 전자: 방향 확인 + 작업자 확인 인정 | 충족 6 |
| 전자: 반대 방향 답변 | 충족 5 + 불일치 1 |
| 전자: 미답변 / 시각 증거만 인정 | 충족 5 + 확인 필요 1 |
| 계측 표준형: C를 5.78 mm로 확인 | 충족 3 |
| 계측 표준형: C 미답변 | 충족 2 + 확인 필요 1 |
| 계측 정밀형: 같은 예시값 사용 | 충족 2 + B 길이 불일치 1 |

안내문에서 실제 버튼과 다른 표현, 질문 확인을 생략한 순서, 존재하지 않는 작업자/작업지시 수정 설명을 고쳤습니다. Python 3의 운영체제별 실행 대안도 추가했습니다. 기능·시나리오·실제 모델 응답 파일은 변경하지 않았습니다.

설명용 [슬라이드 24장](../slides/README.ko.md)을 추가했습니다. 설명 35분 + 실습·토의 175분 + 휴식 30분의 권장 시간표이며, 실제 UI 캡처와 강사 진행 메모를 포함합니다. HTML은 오프라인으로 열리고 PDF·PowerPoint로도 제공합니다. 검수 수치는 기능 검사 결과이며 실제 AI/OCR 정확도나 물리적 검사 승인을 뜻하지 않습니다.

## 강의 직전에 확인할 두 가지

1. 강의 PC에서 전자 조립 영상을 재생해 보세요. 이번 검수용 Chromium은 H.264 디코딩을 지원하지 않았습니다. 장면 사진으로 끝까지 진행하는 대체 경로는 통과했습니다.
2. 한국어 질문 듣기의 음성과 스피커를 확인하세요. TTS 실제 청취는 자동 검사하지 않았습니다. 음성이 없어도 ‘질문 확인’과 버튼·텍스트 답변으로 진행할 수 있습니다.

전체 실습은 서버로, 슬라이드·저장한 보고서는 더블클릭으로 여세요. [시작 안내](../START_HERE.ko.md), [전자 조립 안내](TEACHING_DEMO.ko.md), [계측 안내](MEASUREMENT_DEMO.ko.md)를 함께 배포합니다.

이전 결과와 배포본은 로컬 검수 폴더에 보존했습니다. GPU 작업·자동 감독 메시지·외부 게시를 재개하지 않았습니다. 최종 실행 증거는 `validation/seminar_final_v1`과 `validation/seminar_release_audit_v1`에 별도로 있습니다.
