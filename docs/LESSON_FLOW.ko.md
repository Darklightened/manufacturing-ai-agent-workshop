# 수강생 실습 순서

[최신 화면별 안내](../slides/SCREEN_GUIDE.ko.md) · [시작 안내](../START_HERE.ko.md)

## 준비

실습 주소를 Chrome 또는 Edge에서 열고, 회사별 입력 자료 ZIP을 내려받아 압축을 풉니다. 로그인·모델 설치·API 키는 필요 없습니다. PDF 슬라이드와 완성 예제 ZIP은 선택 자료입니다. 앱은 한 탭에서 사용합니다.

## 실습 1: 전자 조립

1. 회사 폴더 업로드 → 파일 선택 → PDF·CSV·도면 미리보기.
2. 정보 구축 → E-BATTERY 연결을 circuit에서 battery로 수정 → 검토 완료 → 온톨로지.
3. 작업자 이름·사번 등록 → 예시 인증번호6421 → 바람빛 회로 키트 선택.
4. 영상의 여섯 단계를 진행하며 오른쪽 위 검사 항목과 ✓ 확인. 배터리 방향 질문에 답변. 단계마다 **기록 확인 · 모니터링으로** → **다음 작업 시작**.
5. 세부 검사18개·질문·증거 사진 확인 후 DOCX 또는 HTML 검수 보고서 저장.

선택 비교: 영상 근거만 인정하는 기준으로 바꿨을 때 작업자 답변 항목의 보류 여부 확인. DB 상위 기준6개와 영상 세부 확인18개를 구분합니다.

## 실습 2: 계측 검사

1. 표준형 제품 선택 → 도면 A/B/C와 검사 기준 확인 → 정보 구축.
2. 검사자·LOT 입력 → A26.30mm 직접 기록 → **모니터링에서 기록 확인** → **B 측정 시작** → B40.02mm 기록. 같은 방식으로 C 측정으로 이동.
3. C5.?8mm의 확인 질문 → 예시 확인값5.78mm와 단위 입력.
4. 결과 검토 → 검수조서·보고서·필요한 CSV 저장.

계측 장면은 강의용 예시입니다. 영상 재생은 선택 사항이며 입력값과 검사 기준으로 판정을 계산합니다. 모니터링 도면에는 위치별 값이 기입되고, 보고서에는 원래 관찰과 확인값이 함께 남습니다.

선택 비교: A26.60mm 범위 이탈, C578mm 자동 소수점 보정 없음, 기준 변경, 정밀형 B40.02mm 불일치. 모두 할 필요 없이 한 가지를 선택합니다.

## 실습 3: 기계 조립

1. 회사 작업 기준 구축 → 작업 시작 → 실제 공개 조립 영상 재생.
2. 차체 → 브래킷 → 차축·바퀴 → 최종 외관 순서로 진행. 단계마다 **검사 기록 확인** → 모니터링 검토 → **다음 작업 시작**.
3. 가려진 안쪽 연결 핀의 질문에 답변. 확인 불가일 때 보류 유지.
4. 필요하면 ‘다음 작업은 어떻게 하나요?’로 다음 단계 안내 확인.
5. 검사 결과·사진·질문 이력 확인 후 보고서 저장.

작업 안내를 받은 것과 검사 통과는 별개입니다. 외관 영상으로 토크·강도를 확인했다고 기록하지 않습니다.

## 문서 보관함

마지막 메뉴에서 내가 만든 문서와 수업 제공 예제를 구분해 열고, 검색·필터·미리보기·다시 다운로드를 사용합니다. 강사에게 자동 제출되지 않습니다. 제출할 문서는 PC에 저장 후 안내받은 위치로 전달합니다. 다른 PC로 작업을 이어갈 때는 진행 JSON을 별도로 저장합니다.
