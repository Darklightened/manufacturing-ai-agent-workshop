# 학생 실습 안내

실행은 프로젝트의 `START_HERE.ko.md`를 따릅니다. 소개 슬라이드 없이 이 화면과 활동지만으로 실습을 진행할 수 있도록 구성했습니다. 기본 전자 조립은 수업을 위해 작성한 강의용 예시입니다. 실제 모델 호출은 없습니다. 이전 실제 응답과 추가 실습은 강사용 참고 경로에서 선택합니다.

## 공통 실습 회사 자료 구축

1. 첫 화면에서 실습을 고릅니다.
2. 예제 SOP PDF를 열고 교육용 회사·공정·작업 목록을 읽습니다.
3. `정보 구축`을 누릅니다. PDF에서 실제로 추출한 텍스트를 펼쳐 원문과 비교합니다.
4. 검사 기준 CSV와 오른쪽 결과 표를 비교합니다. `실제 SQLite 조회 결과`를 펼쳐 DB에 들어간 행을 확인합니다.
5. `SQLite 저장`으로 파일을 내려받습니다.
6. 작업 설정에서 순서를 확인하고 `작업 시작`을 누릅니다.

필수 검사 항목의 이름·대상·정책을 바꾸면 기존 교육 이벤트를 재사용할 수 없으므로 이 버전에서는 거부합니다. 계측의 수치 범위 변경은 결과 화면에서 지원합니다. 작업 시작 후 원문을 바꾸려면 새 실습으로 시작합니다.

## 전자 조립 — 기본 수업

[전자 조립 실습 안내](TEACHING_DEMO.ko.md)의 여섯 장면을 사용합니다.

1. 예제 SOP와 검사 기준으로 정보 구축을 실행합니다.
2. 준비 → 회로 → 프로펠러 → 배터리 → 스위치 → 최종 확인 순서로 관찰합니다.
3. 배터리가 가려진 장면에서 확인 질문이 생깁니다. **질문 확인**을 먼저 누른 뒤 **방향을 확인했습니다**를 선택하고 남은 장면을 진행합니다.
4. 여섯 검사 항목의 결과와 질문·답변·증거 사진을 보고서로 저장합니다.
5. 답변을 ‘반대로 들어가 있습니다’로 바꾼 결과를 비교합니다.
6. 배터리 항목의 증거 인정 기준을 **시각 증거만 인정**으로 바꾸고 **기준 적용 · 재판정**을 누릅니다. 다시 **작업자 직접 확인도 인정**을 선택해 적용해 보세요. 관찰과 답변은 남고 최종 판정만 재계산됩니다.

제출물: 기본 완료 보고서와 답변/기준 변경 후 보고서, 두 보고서가 다른 이유 한 문장.

이 흐름은 영상으로 설명하는 교육용 상황입니다. 자동 인식 성공률이나 실제 제품 합격 판정으로 설명하지 않습니다.

## 제품별 계측 판독 — 기본 수업

[계측 실습 안내](MEASUREMENT_DEMO.ko.md)를 사용합니다.

1. 첫 화면의 계측 실습에서 표준형 제품을 선택합니다. 제품번호·도면번호·개정·검사 대상이 연결되는지 확인합니다.
2. 정보 구축 후 도면의 A외경·B길이·C두께와 각 허용 범위를 확인합니다.
3. A26.30mm와 B40.02mm를 기록하고 도면 옆 검사표가 채워지는 것을 봅니다.
4. C의 `5.?8 mm`에 대한 질문을 확인합니다. 예시값5.78mm를 직접 입력하고 제출합니다.
5. 검수조서에 확정값·범위·판정·원시 후보·작업자 답변이 함께 남는지 확인합니다.
6. C의 값을578mm로 바꾸는 활동과 범위를 좁히는 활동을 해 봅니다. 입력값을 자동으로 맞춰 주지 않아야 합니다.
7. 새 제품으로 정밀형을 선택합니다. 이전 측정은 섞이지 않고, 새 예시에서40.02mm가 좁은 길이 기준을 벗어납니다.

제출물: 표준형과 정밀형의 검수조서, 원시 후보와 확인값의 차이, 판정이 달라진 이유 한 문장.

## 기존 독립 계측 사진 — 강사용 참고

활동 목표는 원시 판독, 확인값, 규정 비교를 분리하는 것입니다. 세 자료는 같은 제품의 여러 치수가 아닙니다.

1. 디지털 캘리퍼스 관찰을 실행하고 원시 표시 `26.30 mm`와 교육용 범위26.0–26.5mm를 비교합니다.
2. 다음 마이크로미터 사례에서 질문을 확인합니다.
3. 대상을 다른 문자열로 바꾸고 답변을 제출해 연결 오류가 차단되는 것을 확인합니다.
4. 대상을 `micrometer-case`로 복구하고 `5.78`, `mm`를 제출합니다. 이는 학생이 확인한 값이며 자동 판독이나 교정된 치수 인증이 아닙니다.
5. 버니어 사례까지 진행합니다. 보류를 남길 수 있다는 것을 확인합니다.
6. 결과 화면에서 디지털 사례의 상한을26.5에서26.2로 바꾸고 새 기준을 적용합니다. 원시값은26.30으로 유지되며 판정이 범위 밖으로 바뀝니다.
7. 검사 CSV, SQLite, 사진 포함 HTML을 저장합니다.

제출물: 기준 변경 전후의 상태, 원시값과 확인값의 차이, 저장한 측정표.

## 기계 조립과 부품 교체 후 재검사

활동 목표는 다음 작업 진행과 이전 검사 완료를 구분하고, 부품 변경 이후 어떤 증거가 다시 필요한지 이해하는 것입니다.

1. 차체 조립을 선택해 네 작업군과 최종 외관을 확인합니다. 이 원본은 브라우저 호환 문제로 현재 프레임 탐색이 기본입니다.
2. 손에 가린 부분과 마지막 외관 사진이 각각 무엇을 보여 주는지 비교합니다. 토크·강도를 사진만으로 승인하지 않습니다.
3. 결과를 내보냅니다. 새 기계 실습에서 정비 변형을 선택합니다.
4. 정비는 긴 부품을 짧은 부품으로 바꾸는 작업입니다. 처음 상태의 교육용 확인을 기록한 뒤 분리 장면으로 진행합니다.
5. 관련 현재 구성 검사가 새 시도에서 다시 보류가 되는 것을 확인합니다. 보고서에는 이전 기록과 사진이 남습니다.
6. 새 조립 이후의 최종 상태와 남은 검사를 검토하고 정비 보고서를 저장합니다.

제출물: 분리 전후 검사 상태, 다시 확인해야 할 이유, 이전 증거가 보존된 보고서.

## 중단과 복구

실습이 끝날 때마다 `진행 내보내기`를 사용합니다. 브라우저 새로고침은 같은 주소의 저장 상태에서 복구됩니다. 다른 PC나 다른 서버 주소에서는 내보낸 JSON을 `가져오기`로 복구합니다. 시나리오·원문·실행 원장이 맞지 않는 파일은 거부됩니다.

공개 교재의 편집 가능 데이터는 안전한 생산 승인 기록이 아닙니다. 기록 검사는 잘못된 연결·손상·의도하지 않은 상태 변경을 발견하기 위한 교육용 기능입니다.
