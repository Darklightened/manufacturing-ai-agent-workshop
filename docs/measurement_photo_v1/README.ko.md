# 계측 실습의 제품 사진과 모의 영상

실습 2의 표준형·정밀형 제품 선택 화면에 가상 플랜지 부시의 생성 이미지를 표시합니다. A 외경·B 길이·C 두께 장면에는 같은 제품과 계측기를 보여주는 짧은 모의 영상을 배치했습니다.

- **표시:** AI 생성 이미지 / AI 생성 이미지 기반 스마트 글래스 시점 모의 영상
- **재생:** 참고용 선택 기능. 영상을 끝까지 보지 않아도 기존 입력 단계 진행 가능
- **입력 기준:** 사진·영상 아래의 원래 수치 도해와 표시값
- **판정:** 수강생이 직접 입력한 값·단위와 현재 제품의 검사 기준 비교
- **질문:** C의 원시 표시 `5.?8 mm` 보존 후 작업자 확인값 별도 기록

모의 영상은 생성된 정지 이미지에 카메라 움직임을 적용한 설명 자료입니다. 실제 스마트 글래스 촬영, 새로운 측정 과정, 실제 OCR 또는 영상 모델 추론 결과가 아닙니다. 생성 사진의 숫자나 접촉 자세를 실제 측정 근거로 사용하지 않습니다.

검수조서와 보고서는 기존 도면·수치 도해·검사표·질문 및 수정 이력을 유지합니다. 생성 사진을 검사 증거로 대체하거나 완료 항목을 추가하지 않습니다. 기존 세션, 시나리오 식별 정보, 원시 관찰 및 검사 기준은 변경하지 않습니다.
