# 문서 보관함과 다음 작업 안내 · v0.6.3

## 문서 보관함

왼쪽 메뉴의 마지막 **문서 보관함**으로 이동합니다. 보고서 화면에서도 **문서 보관함으로**를 누를 수 있습니다.

- **내가 만든 문서:** 실습에서 파일 저장한 HTML·Word·검사 CSV·진행 JSON·SQLite 사본. 같은 이름의 파일도 저장 시각별로 유지.
- **완성 예제:** 전자 조립, 계측 표준형·정밀형, 기계 조립의 수업 제공 보고서 8종. 내 문서와 구분.
- **미리보기:** HTML 보고서와 CSV·JSON 기록을 화면에서 확인. Word·SQLite는 다운로드 후 관련 프로그램에서 열기.
- **검색·구분:** 제목/파일 이름 검색과 실습별 선택. **삭제**는 확인한 문서함 사본만 제거하며 현재 실습 진행과 PC 다운로드 파일은 유지.

문서 사본은 같은 브라우저의 저장소에 남습니다. 다른 기기에는 자동 전송하지 않습니다. 이 기능을 추가하기 전에 PC에만 다운로드했던 파일을 자동으로 읽지는 않습니다. 기본 완성 예제는 저장 공간 없이 열 수 있습니다.

## 작업자의 다음 공정 질문

기계 조립에서 현재 단계가 통과한 뒤 **다음 작업은 어떻게 하나요?**를 누릅니다. 예를 들어 차체 연결 다음에는 브래킷 배치와 연결 순서를 안내합니다.

> 작업자: 다음 공정은 무엇이고, 어떻게 진행하나요?  
> Agent: 다음 작업은 브래킷 배치입니다. 앞쪽 브래킷을 놓고 연결합니다. 브래킷의 배치는 보이지만 안쪽 연결 핀은 손에 가려져 직접 확인이 필요합니다.

안내는 등록된 작업 순서를 설명하는 강의용 예시입니다. 영상에서 다음 작업의 완료를 관찰한 것으로 처리하지 않으며 기존 판정·진행률·검사 질문 수는 그대로입니다. 질문과 안내는 작업 기록 및 보고서의 **작업 순서 안내**에 별도로 남습니다.
