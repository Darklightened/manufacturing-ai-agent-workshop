# 추가 기능 검수 · v0.6.3

사용자의 후속 요청으로 문서 보관함과 선택형 다음 작업 안내를 추가했습니다. 기존 v0.6.2의 커밋·릴리스·실패 및 성공 기록은 보존합니다.

- 전체 Node **149/149** 통과.
- 문서 보관함 통합 브라우저 **8개 그룹** 통과: 실제 4개 LAB2 내보내기와 LAB1 HTML/Word 저장, 파일 바이트 동일, 같은 이름별 보존, 8개 예제, 검색·필터·복원·선택 삭제, 실습 상태 독립.
- 문서함 독립 브라우저 **8개 그룹** 통과: 미리보기 스크립트·외부 요청 차단, 원본 다운로드, 삭제 취소, 저장 오류, 화면 이동 경합, 데스크톱·모바일 표시.
- 작업 안내: 질문·다음 단계 안내와 별도 보고서 구획, 원래 관찰·판정·검사 질문 수 유지, 새로고침·가져오기 동일.
- 가져온 완료 기록에서 핀 답변을 재확인하면 해당 단계로 이동. 초기 이동 오류와 수정 후 성공 기록을 모두 보존.

문서 보관함은 브라우저의 별도 저장 키를 사용합니다. 파일 저장 시 생성한 사본을 보관하며 이미 PC에만 있던 파일을 자동으로 읽지 않습니다. 실제 장비 판독·모델 정확도·강의실 음성 품질 시험은 아닙니다. 기존 슬라이드는 이후 일괄 개편을 위해 그대로 둡니다.

# 실습 2·3 개편 검수 · v0.6.2

전체 Node 회귀 **135/135** 통과. 새 계측 브라우저 검수 6개 그룹, 기계 조립 통합 검수 9개 그룹 통과. 데스크톱 1440px와 모바일 390px, 이미지·글꼴을 내장한 오프라인 보고서를 확인했습니다. 수업 현장 음성 출력 품질과 실제 장비 판독 정확도 검증은 포함하지 않습니다.

기존 시나리오·모델 응답·원본 미디어·전자 조립 모듈·회사 입력 ZIP·121장 슬라이드는 바이트 그대로 보존했습니다. 기존 시나리오 ID의 의미를 바꾸지 않고 새 ID를 홈의 LAB 02/03에 연결했습니다. 이전 기록은 이전 기준으로 복원합니다. 새 슬라이드는 이후 한 번에 갱신합니다.

이전 값을 새 값으로 덮어쓰거나 소수점을 범위에 맞춰 보정하지 않습니다. A/B 직접 입력은 화면상으로 확인한 값이라는 별도 출처로 기록하며 C의 최초 표시 `5.?8 mm`는 확정된 판독으로 바꾸지 않습니다. 조립 영상은 외관 확인 범위이며 토크·체결력·주행 성능을 측정했다고 표시하지 않습니다.

검수 중 발생한 테스트 코드의 접힌 요소 조회와 잘못된 레거시 입력 포맷은 별도 기록에 보존했습니다. 마지막 검수 결과와 구분하며 실패 기록을 성공으로 덮어쓰지 않았습니다.
