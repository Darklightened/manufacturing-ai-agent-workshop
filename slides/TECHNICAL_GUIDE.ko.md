# 파이프라인 기술 배경과 입출력 예시

구조 설명을 위한 축약 예시입니다. 실제 API 원문이나 모델 평가 결과가 아닙니다.

## 14. 실습 준비: 자료와 결과 파일

**정적 웹과 브라우저 처리** — 화면과 예시 자료를 웹에서 내려받고, 각 수강생의 브라우저 안에서 입력·판정·문서 생성 처리.

- 로그인·API 키 불필요
- 회사 ZIP: 업로드 실습용
- 기록: 개인 브라우저 저장

입력: 실습 링크 + 회사별 입력 자료 ZIP

```text
앱: 웹 주소로 접속
입력: 회사별 폴더
슬라이드: PDF·PPTX·HTML
결과: 보고서·검수조서
```

| 이전 | 이후 |
|---|---|
| 자료 준비 전 | 실습 주소와 회사 폴더 확보 |

완성 예제는 참고 자료. 본인 기록은 실습 후 별도 저장.

앱은 웹 주소에서 실행 · 저장한 HTML 발표본·보고서는 더블클릭 열기

## 21. 실습 1 (전자 조립): 전체 파이프라인

**하네스의 상태 관리** — 현재 작업과 검사 항목을 연결하고, 단계 통과·추가 질문·보고서 생성을 순서대로 실행.

- 작업별 기준 호출
- 영상 근거와 답변 구분
- 통과 신호 후 다음 단계

입력: 바람빛 회로 키트 + 회사 기준 + 조립 영상

```text
공정: 바람빛 회로 키트
준비: 6단계·18개 항목
실행: 작업자 ↔ 모니터링
결과: 검수조서·사진·답변
```

| 이전 | 이후 |
|---|---|
| 배터리 삽입 진행 | 극성 확인 요청 · 단계 대기 |

영상으로 보이는 내용과 작업자가 확인한 내용을 구분하여 기록.

관찰·단계별 신호는 강의용 예시 · 답변·기준에 따른 판정과 문서는 실제 처리

## 23. 실습 1 (전자 조립): 회사 자료의 변환

**문서 추출과 구조화** — PDF의 문자를 꺼내고 CSV 항목·단위를 검증한 뒤, 작업 ID와 검사 기준을 SQLite 표로 연결.

- PDF.js: 문자 추출
- CSV: 원본 기준 6개
- SQLite: 작업 연결 조회

입력: 회사 폴더의 SOP·도면·검사 기준

```text
검사 항목: E-BATTERY
작업 연결: circuit → battery
확인 내용: 배터리 극성
검토 상태: 수정 후 저장
```

| 이전 | 이후 |
|---|---|
| 회사 파일에 분산된 기준 | 검토 완료된 작업별 기준 |

틀린 작업 연결 한 건을 직접 수정하고 관계 그래프에서 재확인.

파일 선택과 미리보기는 실제 동작 · 어떤 파일 조합도 같은 교육용 기준 구축 · 도면 해석은 예시

## 43. 실습 1 (전자 조립): 작업자와 공정 선택

**대상 ID와 작업 세션** — 작업자·공정·기준을 하나의 작업 기록에 연결하고, 선택한 공정의 단계와 검사 목록을 준비.

- 작업자 기록
- 공정별 기준 조회
- 작업 세션 분리

입력: 작업자 김민수 + 전자 조립 공정

```text
작업자: 김민수 / DA-024
공정: 바람빛 회로 키트
작업 단계: 6개
세부 확인: 18개
```

| 이전 | 이후 |
|---|---|
| 작업자·공정 미선택 | 해당 작업의 영상·기준 준비 |

DB 상위 기준 6개를 영상 단계의 세부 확인 18개로 전개. 실제 현장에서는 사내 인증·작업지시와 연동하는 시작 화면.

인증번호 6421은 교육용 화면 인증 · 생체 인증 또는 실제 출입 인증 아님

## 47. 실습 1 (전자 조립): 검사 항목의 자동 진행

**검사 상태와 화면 표시** — 각 확인 항목의 판정 상태를 저장하고, 두 화면에서 같은 기록을 조회. 화면 전환 자체는 검사 결과에 영향 없음.

- 항목별 상태 저장
- 같은 기록의 두 화면
- 미확인 항목 유지

입력: 준비 영상 + 보드·연결 부품·배터리 확인 목록

```text
보드·지시서: 통과 ✓
연결 부품: 현재 확인
배터리: 다음 항목
기록: 모니터링 화면과 공유
```

| 이전 | 이후 |
|---|---|
| 첫 항목 확인 중 | 첫 항목 ✓ · 다음 항목 강조 |

미확인 항목은 질문 대기. 단계의 모든 조건 충족 후 다음 작업 진행.

작업자·모니터링은 동일 기록 사용 · 미확인·불일치의 자동 통과 없음

## 57. 실습 1 (전자 조립): 질문과 통과 신호

**근거 출처와 완료 조건** — 보이지 않는 항목을 자동 통과시키지 않고, 확인 질문의 답변과 해당 항목의 인정 기준을 함께 검증.

- 미확인 항목 유지
- 답변 이력 보존
- 통과 후 다음 단계

입력: 가려진 극성 + 방향 확인 답변

```text
원래 관찰: 극성 확인 불가
화면 표시: ? · 답변 대기
답변: 방향 확인
검증 후: ✓ · 단계 통과
```

| 이전 | 이후 |
|---|---|
| 배터리 단계 보류 | 확인 답변 시 ✓ · 미확인 답변 시 보류 |

확인 불가·반대 방향 답변은 정상 완료와 구별.

작업자 답변의 출처 보존 · 영상 근거만 인정 시 같은 답변으로 통과 불가

## 66. 실습 1 (전자 조립): 검수 보고서 구성

**기록 기반 문서 생성** — 저장된 상태와 검사 기록을 문서 양식에 배치. 보고서 작성 단계에서 새로운 검사 결과를 만들지 않는 방식.

- 세부 검사표
- 관찰·답변 출처
- 실제 DOCX·HTML 저장

입력: 6단계 검사 기록 + 확인 답변 + 증거 사진

```text
표지: 물품 검수조서
본문: 18개 검사 항목과 답변
부록: 6개 공정 증거 사진
출력: DOCX·HTML·인쇄/PDF
```

| 이전 | 이후 |
|---|---|
| 화면에 분산된 작업 기록 | 검수 보고서와 저장 문서 |

승인·서명란은 작성 전 상태 유지. DOCX 편집과 HTML 열람·인쇄 지원.

검수 결과는 교육용 예시 · 문서 보관함은 같은 브라우저에서 조회

## 76. 실습 2 (계측 검사): 전체 파이프라인

**측정값과 규격 비교** — 제품·측정 위치·단위가 맞는지 확인한 뒤, 입력값을 해당 위치의 허용 범위와 비교.

- 도면 위치 연결
- 값·단위 명시
- 제품별 기준 분리

입력: BSH-2630 / A 외경 / 26.30 mm

```text
제품: BSH-2630
기록: A 26.30 mm → ✓
화면: 다음 미완료 항목 B 강조
도면: A 기입값과 출처 저장
```

| 이전 | 이후 |
|---|---|
| 제품·도면·검사 기준 선택 | 측정값 기록 → 판정 → 도면·문서 반영 |

실습은 값을 직접 입력. 실제 현장에서는 OCR·장비값을 같은 항목으로 연결 가능.

강의용 예시 · 입력값·단위·적용 기준에 따른 판정

## 83. 실습 2 (계측 검사): 측정값과 단위

**원시값 보존과 검증** — 입력한 값을 임의로 범위 안에 맞추지 않고, 위치·단위·범위를 확인해 현재 판정과 입력 이력을 함께 저장.

- A 외경 · B 길이 · C 두께
- 입력 오류와 규격 이탈 구분
- 수정 전후 기록 유지

입력: A26.30 mm · B40.02 mm

```text
A: 26.30 mm → 충족
B: 40.02 mm → 충족
C: 미확정
검사자·LOT: 함께 기록
```

| 이전 | 이후 |
|---|---|
| 제품 기준만 조회된 상태 | 치수별 검사표 일부 작성 |

직접 입력 두 번으로 자동 기록과 위치 연결의 의미를 확인.

선택 비교: A26.60 입력 시 불일치 · 값 수정 시 이전 입력 보존

## 86. 실습 2 (계측 검사): 작업자 화면과 모니터링

**검사 상태와 화면의 분리** — 측정값·답변·기준을 하나의 기록으로 보관하고, 작업자 화면과 모니터링 화면에 각각 표시하는 구조.

- 공통 검사 기록
- 통과 항목만 체크
- 다음 미완료 항목 강조

입력: A 외경 26.30 mm · 기준 26.10–26.50 mm

```text
판정: 기준 충족
작업자: A ✓ · B 강조
모니터링: A 26.30 mm 도면 기입
보고서: 동일 값과 확인 출처
```

| 이전 | 이후 |
|---|---|
| A 입력 전 · 기록 대기 | A 기록 후 · B 항목 강조 |

B가 강조되어도 B의 검사값은 입력 전까지 미기록.

체크 표시는 통과 결과의 표시 · 화면 전환에 따른 판정 변경 없음

## 95. 실습 2 (계측 검사): 불확실한 값의 확인

**후보값과 확정값** — 불명확한 원시 표시를 남긴 상태에서 작업자가 확인값을 추가하고, 확인값을 규격과 비교.

- 원시 표시 유지
- 작업자 확인 출처
- 자동 소수점 보정 없음

입력: C 표시 5.?8 mm + 답변 5.78 mm

```text
원시 표시: 5.?8 mm
확인값: 5.78 mm
기준: 5.70–5.90 mm
판정: 충족
```

| 이전 | 이후 |
|---|---|
| C값 미확정 · 질문 대기 | 확인값 기록 · 판정 가능 |

578 입력 시 578로 기록하고 범위 불일치 처리.

표시가 불명확하면 확인 필요 유지 · 정답으로 자동 보정하지 않는 구조

## 106. 실습 2 (계측 검사): 제품별 기준 비교

**측정과 판정의 분리** — 관찰한 숫자 자체와 규격에 따른 판정을 별도로 관리하여, 제품 또는 기준 변경의 영향을 설명.

- 값은 동일
- 적용 기준은 제품별
- 제품 변경 시 새 검사 기록

입력: B 길이40.02 mm + 제품별 도면 기준

```text
표준형: 40.02 → 충족
정밀형: 40.02 → 불일치
값: 동일
판정 근거: 다른 허용 범위
```

| 이전 | 이후 |
|---|---|
| 한 제품의 검사 결과 | 제품별 검수조서 비교 |

새 제품을 선택하면 이전 기록을 섞지 않고 새 검사를 시작.

선택 활동 · 기본 경로 완료 후 한 조건만 변경하여 비교

## 114. 실습 3 (기계 조립): 전체 파이프라인

**작업 진행과 검사 기록의 분리** — 작업자 화면에는 현재 할 일과 확인 상태를 표시하고, 모니터링 화면에는 항목별 결과·증거·답변을 연결. 통과한 항목만 체크한 뒤 다음 미완료 항목으로 전환.

- 같은 검사 기록·다른 화면
- 확인된 항목만 체크
- 질문 해결 후 다음 작업

입력: 차체 조립 영상 + 작업별 검사 기준

```text
브래킷 외관: ✓ 통과
연결 핀: ? 확인 필요
작업자 질문: 핀 삽입 상태 확인
다음 단계: 답변 확인 후 허용
```

| 이전 | 이후 |
|---|---|
| 작업 영상 재생과 검사 대기 | 체크·확인 질문·검사 기록의 연결 |

화면 전환은 보기 방식의 변경. 미확인 항목의 자동 통과 없음.

작업자 화면과 모니터링 화면은 같은 검사 기록 사용 · 미확인 항목은 질문 전후에도 별도 관리

## 121. 실습 3 (기계 조립): 다음 공정 안내

**등록된 절차 기반 안내** — 작업자가 요청하면 미리 등록된 다음 공정과 작업 방법을 안내. 안내를 받았다는 사실만으로 검사 완료 처리하지 않는 구조.

- 현재 단계 참조
- 작업 방법 안내
- 안내와 통과 기록 분리

입력: 차체 단계 완료 + 다음 공정 질문

```text
작업자: 다음 작업은?
Agent: 브래킷 배치
안내: 브래킷 위치·연결 핀 확인
검사 상태: 안내 전 상태 유지
```

| 이전 | 이후 |
|---|---|
| 다음 작업 방법 미확인 | 절차 안내 기록 추가 |

정해진 작업 정보의 조회 예시. 자유형 음성 인식·생성 기능은 포함하지 않음.

음성 대신 예시 질문 버튼 사용 · 검사 판정과 별개의 작업 안내

## 125. 실습 3 (기계 조립): 가려진 부위 확인

**보류와 재확인** — 확인할 수 없는 항목은 보류로 남기고, 후속 답변과 이전 답변을 함께 보존하면서 현재 상태 갱신.

- 불확실성 유지
- 반복 확인 이력
- 단계 통과 조건

입력: 가려진 안쪽 핀 + 작업자 확인

```text
브래킷 외관: ✓ 통과
연결 핀: ? 확인 필요
작업자 확인: 핀 삽입 확인
처리: 핀 항목 체크·단계 통과
```

| 이전 | 이후 |
|---|---|
| 브래킷 단계 대기 | 확인 후 통과 · 다음 단계 허용 |

다음 단계 안내와 실제 연결 핀 검사는 서로 다른 기록.

실제 체결 강도·토크 검사 없음 · 화면으로 확인한 범위만 기록

## 140. 결과 정리: 문서 생성과 보관

**브라우저 저장과 문서 보관** — 실습에서 생성한 파일을 브라우저에 보관하고, 원래 내용 그대로 다시 열거나 내려받는 방식.

- 실습별 문서 구분
- 원본 파일 보존
- PC·브라우저별 기록

입력: 실습별 보고서·검수조서 저장

```text
전자 조립: DOCX·HTML
계측 검사: 검수조서·CSV
기계 조립: 보고서·검수조서
조회: 검색·미리보기·다시 저장
```

| 이전 | 이후 |
|---|---|
