# 설명용 슬라이드

전자 조립과 계측 판독 실습을 안내하는 **34장**입니다. 실제 앱 화면과 공개 조립 장면, 자체 제작 도면을 사용합니다. 준비된 강의용 관찰을 실제 AI/OCR 예측으로 설명하지 않습니다.

제목은 **실습 1(전자 조립): 데이터 변환**과 같은 주제형 표기, 본문은 명사형 불릿으로 구성합니다. 실제 UI 캡처의 문구는 원본을 유지하며, 강사 발화 메모는 문장형입니다.

## 파일 선택

- [HTML 발표본](실습_안내.html): 더블클릭으로 실행. 그림·글꼴 내장, 인터넷이나 서버 불필요.
- [PDF](실습_안내.pdf): 인쇄·공유용 34쪽. 검색 가능한 한국어 텍스트 포함.
- [PowerPoint](실습_안내.pptx): 동일 화면을 보존한 16:9 발표용 34장과 발표자 노트. 슬라이드 본문은 이미지 형태입니다.
- [강사 진행 메모](INSTRUCTOR_NOTES.ko.md): 단계별 발화·버튼·예상 결과·문제 대응·제출물.
- [편집 원고](content.json): 슬라이드 문구와 시간표. 수정 후 제작 스크립트로 다시 만들 수 있습니다.

HTML 조작: **← →** 이동, **N** 강사 메모, **O** 목차, **F** 전체화면. 화면 그림을 클릭하면 확대하고 **Esc**로 닫습니다. 메모는 기본 숨김이며 PDF에는 포함하지 않습니다. PowerPoint에는 동일 메모가 발표자 노트로 들어 있습니다.

## 강의 진행

**첫 25분은 솔루션 소개·필요성·배경**, **다음 25분은 자료 접속·다운로드·준비**입니다. 준비 구간은 설명 8분과 수강생 직접 조작 17분으로 구성합니다. 10분 휴식 후 본 실습을 시작합니다.

| 경과 시간 | 슬라이드 | 내용 |
|---|---|---|
| 00:00–00:25 | 01–09 | 제조 업무의 필요성 · AI Agent · 솔루션 구조 · 적용 예시 |
| 00:25–00:50 | 10–15 | 사이트 접속 · 파일 다운로드 · 자료 열기 · 화면 탐색 · 준비 점검 |
| 00:50–01:00 | — | 휴식 |
| 01:00–02:00 | 16–22 | 전자 조립 · 질문 · 기준 비교 · 보고서 |
| 02:00–02:10 | — | 휴식 |
| 02:10–03:15 | 23–31 | 계측 검사 · 수치 확인 · 제품별 기준 비교 · 검수조서 |
| 03:15–03:25 | — | 휴식 |
| 03:25–04:00 | 32–34 | 진행 복구 · 현장 적용 · 결과 정리 |

총 240분 = 설명 61분 + 접속·실습·토의 149분 + 휴식 30분입니다. 기존 실습 내용은 유지하되 반복 활동의 횟수를 조절합니다.

수강생은 [온라인 실습](https://darklightened.github.io/manufacturing-ai-agent-workshop/) 링크를 엽니다. 로그인·설치·API 키는 필요 없습니다. [자료실](https://darklightened.github.io/manufacturing-ai-agent-workshop/downloads.html)에서 슬라이드 PDF와 예제 자료 ZIP을 받습니다. 앱 내에도 같은 예제가 제공됩니다. 슬라이드의 UI 그림은 캡처이며 실제 조작은 별도 실습 탭에서 진행합니다.

## 출처와 확인 범위

전자 장면: EgoOops S1790005, Yuto Haneji 외, CC BY-SA 4.0. [원본 프로젝트](https://y-haneji.github.io/EgoOops-project-page/)와 [자료별 라이선스](../DATA_LICENSES.md)를 참고하세요. 계측 그림·제품·도면은 이 실습용 자체 제작 예시입니다. 글꼴은 Noto Sans KR, SIL OFL 1.1입니다.

HTML/PDF와 PowerPoint 이미지가 동일한 검수된 HTML 장면에서 만들어집니다. HTML의 키보드·메모·목차·확대·작은 화면 맞춤·오프라인 이미지 표시와 PDF 34쪽, PPTX 34장·노트 구성을 검사합니다. PowerPoint 설치 프로그램에서의 직접 슬라이드 쇼 검증은 하지 않았습니다.

제작용 명령은 `python scripts/build_slides.py`와 `python scripts/export_slides.py --browser <Chromium 실행파일> --output <새 검수 폴더>`입니다. 제작자는 Playwright·python-pptx·Pillow·PyMuPDF가 필요하지만 강의 참가자에게는 필요 없습니다. 제작 스크립트는 외부 게시나 모델/GPU 실행을 하지 않습니다.
