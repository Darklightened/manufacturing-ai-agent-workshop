## 현재 화면의 진행 순서

1. 회사 자료 구축 → 작업자·제품·공정 선택
2. 작업자 화면: 큰 영상과 오른쪽 위 검사 목록
3. 통과 항목의 체크 유지 → 다음 미완료 항목 강조
4. 미확인 항목의 질문 → 작업자 확인 → 판정 갱신
5. 모니터링 화면: 같은 기록의 검사표·도면·증거 확인
6. 다음 작업자 화면 → 전체 결과 검토 → 검수조서·보고서 저장

빨간 네모는 눌러야 할 버튼·입력란입니다. 검사 항목을 확인하는 장에서는 눌러야 할 버튼 없이 체크 변화 자체를 보여줍니다. 조작은 실습 탭에서 진행하며 HTML 발표본의 이미지는 클릭해 확대할 수 있습니다.

PDF·CSV 추출, DB 구성, 입력 검증, 판정과 보고서 생성은 실제 앱 처리입니다. 영상 관찰·질문 안내는 준비된 강의용 예시이며, 실습에 GPU·API 키·별도 모델 설치가 필요하지 않습니다. 음성은 브라우저 읽어주기이며 답변은 버튼·텍스트 입력입니다.

보고서는 A4 검수 양식으로 출력합니다. 계측 모니터링과 검수조서에는 측정값이 도면 위치별로 연결됩니다. 문서 보관함은 현재 브라우저의 기록으로, 강사에게 자동 제출되지 않습니다.
