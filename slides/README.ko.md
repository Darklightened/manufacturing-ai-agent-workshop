- [PowerPoint](실습_안내.pptx): 화면 보존형 이미지 슬라이드, 발표자 노트, 계측 모의 영상 1개 내장.

## 화면과 예시의 의미

빨간 네모는 실제 버튼·입력란의 위치입니다. 슬라이드에서는 그림 확대, 조작은 별도 실습 탭에서 진행합니다. 전자 조립은 DB 상위 기준6개를 영상 세부 확인18개로 전개합니다. 계측은 A/B 직접 입력과 C 확인 질문을 사용합니다. 기계 조립은 네 단계·여섯 기준과 가려진 연결 핀 확인, 선택적인 다음 작업 안내를 포함합니다.

계측 사진은 **AI 생성 이미지**입니다. 모의 영상은 생성 정지 이미지에 시선 이동을 표현한 것으로, 실제 스마트 글래스 촬영이나 물리적인 계측 동작 영상이 아닙니다. 입력값·판정은 사진의 픽셀에서 추론하지 않고 직접 입력한 값과 검사 기준으로 계산합니다. 보고서는 기존 도면·관찰 표기·입력 이력을 보존합니다.

회사 업로드는 파일 선택·미리보기를 실제 수행하며, 선택 조합과 관계없이 공통 교육용 자료로 구축합니다. PDF 문자 추출·CSV 검증·SQLite·답변·판정·문서 생성은 실제 앱 처리입니다. 도면 해석·영상 관찰·질문 안내는 강의용 예시이며 실습 중 모델/GPU 호출은 없습니다.

## 보관과 출처

문서 보관함은 현재 PC의 같은 브라우저에서 생성한 문서를 표시합니다. 다른 PC 또는 강사에게 자동 공유되지 않으므로 필요한 파일은 따로 저장·제출합니다.

[소개자료 반영 범위](REFERENCES.ko.md) · [공개 영상 라이선스](../DATA_LICENSES.md) · [생성 이미지 프롬프트](../assets/measurement-photo-v1/prompts.json). 회사 원본 PPTX나 비공개 HTech 자료는 포함하지 않습니다.

PPTX는 문구가 개별 텍스트 상자인 편집형이 아니라 화면 보존형입니다. 문구 수정은 content.json에서 수행합니다. 실제 강의 PC의 PowerPoint 영상 재생과 음성 출력은 수업 전 점검 항목입니다.
