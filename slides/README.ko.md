# 설명용 슬라이드

**121장**으로 구성한 제조 AI Agent 강의와 실습 조작 안내입니다. 기존 소개 12장에 **파이프라인·단계 설명 16장**, **실제 화면 93장**을 연결했습니다. 준비·전자 조립·계측·저장/복원의 필요한 조작 위치를 빨간 네모로 표시합니다.

## 파일 선택

- [HTML 발표본](실습_안내.html): 이미지·글꼴 내장, 더블클릭 실행. 그림 클릭 확대·목차·강사 메모.
- [PDF](실습_안내.pdf): 인쇄·공유용 화면별 안내.
- [PowerPoint](실습_안내.pptx): 화면 보존형 이미지 슬라이드와 발표자 노트.
- [강사 진행 메모](INSTRUCTOR_NOTES.ko.md): 조작 순서·입력/출력·비교 조건·시간표.
- [화면별 빠른 찾기](SCREEN_GUIDE.ko.md): 슬라이드 번호와 버튼·파이프라인 단계.
- [편집 원고](content.json): 문구·시간표·실제 캡처 경로.

## 화면 읽는 방법

각 실습은 전체 파이프라인 설명으로 시작합니다. 자료 구축·관찰·질문·판정·보고서로 역할이 바뀌는 지점에도 설명 장을 둡니다. 조작 화면 상단에서 현재 단계를, 오른쪽에서 입력·시스템 처리·확인할 결과를 확인합니다. 빨간 네모는 실제 화면의 버튼과 입력란 위치입니다. 읽기 전용 도면·검수조서에는 조작 표시가 없습니다.

슬라이드 그림에서 버튼을 눌러 앱이 실행되지는 않습니다. 실제 조작은 별도 [실습 탭](https://darklightened.github.io/manufacturing-ai-agent-workshop/)에서 진행합니다. HTML의 ←/→ 이동, N 메모, O 목차, F 전체화면을 사용할 수 있습니다.

## 강의 진행

소개 25분, 접속·준비 25분, 첫 휴식 10분을 유지합니다. 이후 실습은 화면을 따라 직접 조작하고 조건을 바꿔 비교하는 시간입니다.

| 00:25–00:50 | 13–23 | 자료 접속·다운로드·실습 준비 |

| 02:00–02:10 | — | 휴식 |
| 02:10–03:15 | 63–114 | 실습 2(계측 검사): 측정값과 검수조서 |

## 실제 실행과 예시의 구분

원본 조립 장면은 공개 영상이며, 관찰 내용과 계측 도해·최초 판독은 강의용 예시입니다. PDF 추출·CSV 검증·SQLite·질문/답변·판정·보고서·복원은 실제 앱 경로에서 확인했습니다. 미리보기와 확대는 관찰 기록을 추가하지 않습니다. 정밀형에서도 새 기록을 시작해 전체 측정과 확인을 반복합니다.
